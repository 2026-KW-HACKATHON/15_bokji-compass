# 공고 마감 D-Day (2026-10-08)

공고마다 마감까지 남은 일수를 공통 `PolicyDeadline`으로 표시합니다.
전체 공고·추천·저장 공고의 일반/쉬운 카드, 공고 상세, 캘린더의 날짜별/상시 목록에 적용합니다.

- 미래 마감: D-7처럼 남은 날짜 표시. 7일 이내는 강조색을 사용합니다.
- 오늘 마감: D-Day. 다음 날부터 마감 D+1처럼 경과 날짜 표시.
- 종료일 없는 상시 공고: 상시 접수. 마감일 누락/잘못된 날짜: 마감일 확인 필요.
- `3~4월`처럼 월 범위가 서버에서 확장된 공고도 해당 종료일인 4월 30일을 사용합니다.

`deadlineModel.policyDeadline(policy,today)`은 `{state,days}`를 반환합니다.
서버 `applicationEnd`만 사용하고 신청 기간 문자열을 임의로 다시 해석하지 않습니다.
브라우저 시간대나 접속 시간이 아닌 한국 날짜끼리 UTC 기준 정수 일수를 비교합니다.
캘린더에서 다른 날짜를 선택해도 실제 오늘에 대한 D-Day가 유지됩니다.

`useSeoulToday()`는 `useSyncExternalStore`와 한 개의 공통 타이머로 한국 자정에
표시를 갱신합니다. 탭/창 복귀 때 날짜를 확인하며 구독자가 없으면 타이머와 리스너를 해제합니다.
캘린더의 오늘 표시·오늘 버튼·접수 마감 상태도 같은 한국 날짜를 구독합니다.
날짜 갱신은 추가 API 호출을 하지 않습니다. 접근성 이름은 남은/경과 일수를 풀어 설명하고
UI 문구는 영어·중국어·베트남어·일본어도 제공합니다.

검증은 날짜 모델의 상태·윤년·월말·새해·한국 자정·다른 시간대 테스트와
PC/모바일의 카드·상세·저장·캘린더·자정 자동 갱신 E2E, 웹 전체 단위 테스트와 빌드입니다.
