# 쉬운 화면의 대칭과 기준선 정렬

2026-10-08 · 웹 쉬운 화면의 헤더·홈·전체 메뉴·공고 카드를 정돈했습니다.

## 배치

- `easy-shell.css`의 공통 폭 1120px와 좌우 여백 24px(600px 이하 16px)을 사용해 헤더 메뉴·본문·하단 챗봇 도움말의 시작과 끝을 맞춥니다. 스크롤바가 생겨도 같은 컨테이너 폭을 기준으로 계산합니다.
- 헤더의 언어 레이블·선택·모드 전환·로그인을 세로 중앙에 맞춥니다. 전체 메뉴는 대메뉴와 하위 메뉴를 일정한 열에 나란히 놓고, 태블릿에서는 제목 아래 같은 폭의 하위 메뉴, 모바일에서는 한 열로 펼칩니다. 기존 `EasyNavigation`의 키보드·초점·경로 이동 계약은 유지합니다.
- 홈의 지역 선택·검색어·검색 버튼은 56px 기본 높이와 같은 기준선을 사용합니다. 관심 분야는 같은 폭의 5열, 모바일은 2열이며 마지막 항목을 전체 폭으로 표시합니다.
- 동네 복지·지원 분야·AI 비서 카드의 아이콘/본문/행동 열과 내부 여백을 맞춥니다. PC 행동 열은 12rem, 좁은 화면에서는 재배치하며 모바일 버튼은 전체 폭으로 표시합니다.
- 공고 목록은 본문과 일정한 폭의 상세 버튼을 나란히 놓고 680px 이하에서는 본문 아래 전체 폭 버튼을 표시합니다. 긴 본문·조건을 자르지 않고 읽기 순서를 유지합니다.

## 파일과 호출

`web/src/app/easy-shell.css`는 공통 정렬·홈·메뉴, `easy-features.css`는 공고와 도움말 폭을 담당합니다. React 컴포넌트의 인자·반환값·서버 API와 저장 동작은 바뀌지 않습니다. 별도 의존성은 추가하지 않았습니다.

## 검증

PC 1440px와 모바일 390px 캡처를 확인했습니다. 검색의 세 제어 높이는 모두 56px이며 PC 헤더·본문·도움말의 왼쪽 기준선은 184px로 일치합니다.

- 한국어·영어·중국어·베트남어·일본어 × 10개 폭(320~1440px), 총 50개 조합에서 헤더·본문·도움말의 좌우 정렬과 전체 메뉴를 열었을 때의 가로 넘침을 확인했습니다. 모든 조합에서 기준선 차이와 가로 넘침은 0px였습니다.
- 기존 공고 카드·헤더 로그인·메뉴·홈 검색 E2E는 PC/모바일 23개 통과, 모바일 hover 전용 1개 제외입니다. 개발 화면 갱신으로 끊긴 모바일 카드 검사는 최종 CSS에서 재실행해 통과했습니다. 공고 320~1440px, 긴 본문과 큰 조회수, 키보드 상세 열기를 포함합니다.
- 단위 검사 162개는 160개가 샌드박스에서 통과했습니다. 로컬 연결 권한으로 실패한 전시 QR 검사 2개는 해당 파일의 4개 검사 전체를 권한이 있는 환경에서 재실행해 통과했습니다.
- 최종 Vite 운영 빌드, 변경 CSS의 Prettier 검사와 공백 검사 통과. 기존 청크 크기 경고가 남습니다. 운영 배포 파일은 갱신하지 않았습니다.
