# 정보 부족 시 홈 추천 안내

2026-10-07. 담당: 프론트엔드.

홈은 비회원·프로필 미입력 상태에서도 공개 추천 API를 요청한다. 서버가 응답한
`mode`와 `profile_sufficient`를 보존하며, 완료된 개인화 응답에서만 배너·쉬운 화면 제목에
내 정보와 맞는다는 표현을 사용한다. 저장된 지역·관심사 등 일부 정보가 있는 상태도
그 자체로 충분한 조건 비교가 이루어진 것으로 취급하지 않는다.

일반 후보는 카드 위 제목과 카드 아래 정보 부족 설명을 함께 제공한다. 인기 후보는
정부24/복지로 공식 제공처의 누적 조회수에 근거한다. 인기 표시가 현재 이용 인원이나
최근 관심 추세를 뜻하지 않는다. 안전 후보가 없으면 정보 추가를 안내하며 서비스 장애의
오류·재시도 화면과 구분한다. 정보 추가 버튼은 기존 내 정보 화면으로 연결한다.

카드는 서버에서 받은 공식 누적 조회수와 수집일을 표시한다. 예산 소진률은 명시된
0~100 수치·HTTPS 근거·근거 문장이 모두 있는 응답에서만 표시한다. 기준일이 없으면
미제공으로 표시한다. ‘예산 소진 시 조기 마감’ 등 원문 안내는 별도의 예산 안내로 표시하며
날짜·조회수로 퍼센트를 계산하지 않는다. 지표가 없는 공고는 숫자 없이 표시한다.

관련 함수와 필드 계약은 [추천 모듈](../web/src/features/assistant/readme.md),
[공고 모듈](../web/src/features/policies/readme.md)에 기록했다. 백엔드의 실제 안전 후보 선정과
공식 조회수 수집은 [서버 인기 지표](../../backend/docs/policy-popularity.md)를 따른다.

검증 코드는 Node 계약 테스트 `tests/recommendation-context.test.js`와
브라우저 회귀 `tests/e2e/recommendations.spec.js`에 있다. 기존 공고·달력 회귀도 함께 확인한다.
브라우저 응답 대역 검증은 실제 운영 공고의 자격 충족이나 제공처의 실시간 갱신을 의미하지 않는다.

실행 확인: 전체 Node 계약 테스트 66개 통과, 추천·기존 앱·달력의 데스크톱/모바일
브라우저 50개 통과 뒤 개인화 성공 응답을 추가하여 추천 18개 재실행 통과(고유 시나리오
52개). 변경 코드의 Prettier 검사와 격리 운영 빌드도 통과했다. 수집·기준 시각은 서울
시간대로 표시하며 UTC 자정 근처의 날짜 변환을 계약 검사에 포함했다. 320px 일반/쉬운
화면 캡처에서 일반 공고·정보 부족 설명·정보 추가 버튼과 인기/예산의 출처 표시를 확인했다.
