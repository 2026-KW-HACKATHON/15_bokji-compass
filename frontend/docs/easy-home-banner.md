# 쉬운 화면 홈 배너 단순화

2026-10-06: `AssistantHome({ easy, ... })`는 쉬운 화면에서 `HomeBanner`를 생성하지 않습니다. 따라서 자동 전환 타이머·달력 홍보·배너 조작부도 생성하지 않습니다.

쉬운 홈에는 일반 페이지 제목·한 줄 안내·맞춤 공고 찾기(정보가 있으면 내 정보 수정) 버튼을 표시합니다. 큰 장식 로고와 배너 배경은 제거했습니다. 추천 공고·정보 수정·전체 공고 진입·공고 출처 푸터는 유지합니다.

일반 화면은 기존 `HomeBanner`로 추천 안내와 캘린더 홍보를 제공합니다. 쉬운 화면에서 일반 화면으로 전환하면 배너가 다시 생성됩니다.

검증 완료: 웹 빌드와 변경 JSX의 Prettier 검사 통과. 실제 Edge에서 1440px·390px·320px의 쉬운 화면을 캡처하고 배너·조작부 제거와 가로 넘침 없음을 확인했습니다. 16초 시간 진행 후에도 배너가 생성되지 않으며, 맞춤 공고 찾기 버튼의 정보 입력 이동과 일반 화면 복귀 시 배너 표시, 달력 홍보 배너에서 쉬운 화면 전환 시 배너 제거를 확인했습니다. 화면 검증의 API 응답은 모킹했습니다.
