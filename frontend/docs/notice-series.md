# 같은 사업의 단계별 공고 표시

2026-10-08 구현. 광운대 국가근로장학금처럼 같은 사업의 신청·추가 절차·선발 결과가
각각 게시되어도 목록에서는 한 묶음으로 표시한다. 게시 기관·사업·연도·학기·차수가
다른 공고는 구분하며 원문 제목·본문·첨부는 각 상세에 보존한다.
사용자 선택에 따라 실제 모집 차수마다 카드를 따로 유지한다. 기간 연장·재공고는
같은 회차 안에서 연결하며 지급1~4차는 같은 학기 지급 일정 안내로 한 카드에 표시한다.

목록 카드는 서버의 선택 메타데이터 `noticeGroup`을 받아 묶음 제목, 최신 단계와
‘관련 공고 N개’ 접기 목록을 표시한다. 신청 안내·신청자 추가 절차·선발 결과를 표시하고
각 게시글의 날짜와 공식 원문 링크를 제공한다. 키보드로 목록을 펼칠 수 있고 좁은 화면에서
긴 제목과 링크가 줄바꿈된다. 관련 공고가 없는 기존 API 응답도 기존과 같이 표시한다.

상세는 현재 선택한 원래 공고 제목과 본문을 유지한다. 관련 공고 목록에는 현재 보고 있는
원문을 표시한다. 후속/결과 단계의 문서 또는 묶음에서는 새로 신청하는 버튼과 마감 강조를
제거하고 기존 신청 방법·준비 서류는 읽을 수 있도록 제공한다. PDF·첨부 파일 보기와
원문 확인은 계속 이용한다. 선발 결과가 개인의 선발 여부를 확정하는 것으로 표시하지 않는다.
공통 `ApplicationGuide`도 같은 단계를 직접 확인하므로 챗봇에서 선택한 결과 공고에
새 신청 액션이 생기지 않는다. 신청·접수·모집 마감/종료 제목은 ‘모집 종료’로 표시한다.
명시적인 후속 지급 안내는 ‘지급 안내’로 표시하고 지급 대상·일정의 공식 확인을 안내한다.

`noticeSeriesModel.js`는 선택 메타데이터의 ID·제목·단계·날짜·중복 항목을 검증하고
공식 원문 주소를 `safeWebUrl`로 정제한다. 메타데이터가 잘못되어도 원래 공고는 유지한다.
`NoticeSeries.jsx`/`notice-series.css`는 카드 접기 목록과 상세 목록을 공유한다.
고정 안내는 기존 한국어·영어·중국어·베트남어·일본어 사전에 등록한다.

검증은 `notice-series.test.js`와 `e2e/notice-series.spec.js`에 있다. PC/모바일의
묶음 제목·단계, 원문 3개 링크, 키보드, 선택 원문과 첨부 보존, 실제 신청 액션 차단,
320px 쉬운 화면을 확인한다. 서버의 묶음 기준과 추천 제외는
[백엔드 계약](../../backend/docs/notice-series.md)을 따른다. 실행 결과는 작업 기록에 남긴다.

2026-10-08 사용자 요청으로 최신 웹 빌드와 API를 운영 반영했다. 공개 사이트의 PC·320px
모바일에서 광운대 176개, 지급 안내의 관련 원문 4개와 원래 상세·공식 링크·신규 신청
액션 제거를 확인했다. 공개 정적 자산은 새 빌드와 해시가 일치하며 DB 준비 상태도 정상이다.
[운영 확인과 복구 기록](../../backend/docs/notice-series.md#운영-반영-확인)을 참고한다.
