# 웹 공고 출처 푸터

2026-10-06: 메인 페이지 하단에 공식 사이트 로고를 모은 공고 출처 영역을 표시합니다. 다른 페이지에는 기존 브랜드 푸터만 표시합니다.

- `SourceFooter({ showSources = false })`는 브랜드와 공통 주의 문구를 반환하며, `showSources`가 참일 때 정부24·복지로·서울특별시·광운대학교 로고와 링크도 표시합니다. `App`은 `route.page === 'home'`일 때만 출처를 표시합니다.
- 2026-10-08: 일반·쉬운 화면 모두 페이지 하단에 “AI는 실수할 수 있습니다. 안내·계산은 참고용이며, 실제 지원 여부와 금액은 심사 결과에 따릅니다.”를 한 번 표시합니다. 영어·중국어·베트남어·일본어도 간결하게 번역했습니다. 기존 `72ch` 폭 제한을 제거해 넓은 화면에서 한 줄로 표시하며 좁은 화면은 자연스럽게 줄바꿈합니다.
- 문구·배치 수정 검증: 단위 163개와 기존 계산기 PC/모바일 검사 2개 통과. PC 일반/쉬운 화면의 실제 텍스트 한 줄 및 모바일 가로 넘침 없음, 빌드와 변경 코드 포맷을 확인했습니다.
- 출처 목록은 백엔드 `collectors`의 지원 사이트를 기준으로 정리한 정적 안내입니다. 백엔드 내부 모듈이나 수집 원본을 프론트엔드에서 참조하지 않습니다.
- 각 링크는 `target="_blank"`, `rel="noopener noreferrer"`와 새 창 안내를 제공합니다. 광운대학교는 공지사항으로 연결합니다.
- 정적 이미지와 사이트 이름을 함께 제공하며, 로고는 장식 이미지로 처리해 링크 이름이 중복되지 않습니다.
- 넓은 화면은 4열, 900px 이하 화면은 2열입니다. 쉬운 화면에서도 출처를 표시하며 글자를 확대합니다.
- 최초 추가 시 검증: `npm run build`와 변경한 JSX/CSS의 Prettier 검사 통과. 실제 Edge에서 1440px 일반 화면, 390px 일반·쉬운 화면, 320px 쉬운 화면의 로고 4개 로딩·새 창 링크 속성·가로 넘침 없음을 확인했습니다. 캡처를 직접 확인했으며, 화면 검증의 API 응답은 모킹했습니다.
- 메인 전용 표시 수정 후 검증: 빌드와 변경 JSX의 Prettier 검사 통과. 브라우저에서 일반 화면의 메인에는 로고 4개, 전체 공고·저장한 공고·캘린더·계산기·내 정보·로그인·회원가입에는 출처 영역이 없고 브랜드 푸터는 남아 있음을 확인했습니다. 쉬운 화면의 메인 로고 4개 로딩과 로그인·회원가입의 출처 영역 제거도 확인했습니다. 기존 로그인 디자인 E2E는 PC·모바일 2건 통과했으며, 일반·쉬운 화면 캡처를 저장했습니다.

원본 자산 위치는 [로고 안내](../web/public/source-logos/README.md), 호출 위치는 `frontend/web/src/app/App.jsx`입니다.
