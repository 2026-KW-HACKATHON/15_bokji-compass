## 2026-10-08 — 8001 로컬 관리자 로그인 복구

- 재시작 뒤 production HTTPS 검사가 직접 HTTP로 여는 로컬 관리자 콘솔까지 거부했다.
  DB의 최고관리자 권한은 정상이었으나 콘솔이 모든 403을 권한 오류로 표시했다.
- 실제 loopback 접속자·로컬 Host·전달 헤더 없음인 서버 관리자 API에 한해 로컬 HTTP를
  지원한다. 공개 API HTTPS·동일 출처·매 요청 최고관리자 검사와 HttpOnly/Strict는 유지하고,
  HTTPS 쿠키의 Secure도 유지한다. 오류 문구는 전송·출처·권한 문제를 구분했다.
- 콘솔 회귀 71개, 최종 전송 경계 26개, Ruff·JS 구문 검사 통과. 첫 IPv6 검사의
  TestClient URL 파싱 한계는 Host 헤더 방식으로 보완하고 전송 검사 전체를 재통과했다.
- 소유 백엔드를 재시작해 운영 반영했다. 실제 8001 콘솔 session 401·빈 로그인 입력 422,
  공개 계정 HTTP/전달 헤더 HTTP 403, 공개 HTTPS ready 200과 로그인 화면 정상 표시 확인.
  운영 계정 비밀번호·등급은 변경하지 않았으며 실제 자격증명 로그인은 사용자에게 맡긴다.
