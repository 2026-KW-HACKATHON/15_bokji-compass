# Android·iOS 앱 이식 기록

기준: 2026-10-01. 담당: 프론트엔드/모바일·인증 백엔드. 사용자 요청에 따라 기존 Android Java 계획을 Android·iOS 공통 React Native + Expo 개발로 변경했습니다.

## 이번 구현 범위

- `frontend/mobile`에 Expo SDK 57·React Native 0.86·TypeScript·Expo Router 프로젝트 생성.
- 홈·내 계정·단계별 소득/재산 계산·쉬운 화면, 명시적인 금융 저장/조회/삭제.
- 기기 SecureStore 세션 보관·앱 시작 시 조회·만료 처리·로그아웃 재시도.
- 웹과 앱이 같은 금융 입력 검증·질문 정의를 사용하도록 `frontend/packages/core` 분리. 기존 웹 import 경로 유지.
- `/v1/mobile/auth/login`, `/me`, `/logout` 추가. 기존 금융 API는 모바일 Bearer와 기존 웹 쿠키를 지원하고, 잘못된 Authorization이 있으면 쿠키로 우회하지 않음.
- 서명·클라우드 계정 없이 로컬에서 확인 가능한 빌드/테스트와 EAS 프로필 준비.
- 공개 공고 검색·상세 조회, 상단 고정 쉬운 화면, 중위소득 계산기 명칭과 모바일 정보량 조정.
- 홈 이미지 배너 3장·스와이프·이전/다음·기능 바로가기. 로컬 장식 이미지이며 공고 데이터와 독립적입니다.
- Android 백업·권한·통신·화면 보호, 의존성 패치, APK 배포 차단 검사 도구.

## 단계별 상태

| 단계 | 상태 | 완료/후속 기준 |
|---|---|---|
| 폴더·앱 골격 | 구현 | Expo 설정과 홈·공고·계산기·내 계정 4개 탭, 실행 안내 |
| 인증·금융 API | 구현 | 서버 테스트·세션 상태 테스트·실제 API 브라우저 연결 검사 |
| 공통 금융 로직 | 구현 | 기존 웹 테스트·빌드 회귀 확인 |
| Android/iOS 실행 | Android 에뮬레이터 실행 확인, iOS 번들 검증 | 실제 휴대폰·iOS 개발 빌드·접근성·오프라인 동작 후속 검증 |
| 공고 탐색 | 구현·공개 데이터 대기 | 검색·분야/지역·정렬·페이지·상세·공식 링크, 공개 API 연결 |
| 추천·저장 공고·프로필·가입 | 후속 | API 계약 확인 후 순차 이식 |
| 푸시·딥 링크·스토어 배포 | 후속 | 서버 토큰 계약·기기 권한·서명·소유 앱 식별자 확정 |

모바일 번들 생성은 APK/IPA 설치나 스토어 심사를 의미하지 않습니다. 브라우저 미리보기에서 토큰은 메모리에만 두므로 네이티브 보안 저장의 재실행 검증을 대신하지 않습니다. 현재 금융 초안은 로그인 상태 전환 시 모두 초기화됩니다. 비회원 초안을 로그인 후 유지하는 흐름은 후속 UX 작업입니다.

## 검증 기록

최신 재검토 결과와 배포를 막는 조건은 [모바일 보안 재검토](mobile-security-review.md)를 기준으로 확인합니다. 아래 초기 검증 수치는 각 작업 시점의 기록입니다.

- 인증·금융 백엔드 회귀: 47개 통과. 격리 SQLite 사용, 기존 의존성 deprecation 경고 2건.
- 모바일 HTTP·세션·금융 입력 테스트: 14개 통과.
- 기존 웹 테스트: 26개 통과, Vite 운영 빌드 성공.
- 모바일 TypeScript·ESLint 통과. Expo Doctor 21/21 통과.
- Android·iOS Hermes 번들 생성 성공. Android x86_64 debug APK 빌드·설치·실행 성공. iOS 설치/실행과 실제 휴대폰은 미검증.
- Android 14 에뮬레이터에서 로그인·강제 종료 후 SecureStore 세션 복원·로그아웃 후 재실행 확인. 일반 AVD `U_Pixel_2_`에서 화면·키보드·뒤로 가기로 키보드 닫기·탭 이동·10단계 계산 API 응답 확인. ATD `Pixel_2_API_34`는 화면 렌더링이 꺼진 자동 테스트 이미지이므로 수동 테스트는 일반 AVD 사용.
- Windows `npm run android:local -- -ApiBaseUrl http://127.0.0.1:8766`으로 SDK/JDK 선택·adb reverse·IPv4 localhost Metro·APK 빌드/설치/실행 검증. 최초 Gradle 빌드 21분 28초(도구/의존성 다운로드 포함), 캐시 재빌드 39초. 네이티브 크래시/ReactNativeJS 오류 로그 없음.
- 격리 SQLite 실제 API + Edge 390px 미리보기에서 로그인→계산→동의 저장→화면 초기화→불러오기→삭제 취소/확정→로그아웃→금융 메모리 제거를 확인. 페이지 JavaScript 오류와 가로 넘침 없음. [작업 기록](worklog.md).
- 초기 npm audit moderate 13건은 후속 보안 작업에서 패치 버전과 호환 어댑터로 해결했습니다. Android Maven 의존성 187개 OSV 조회에서 발견한 Gson·Commons IO도 수정했습니다. 후속 npm/OSV 검사에서 알려진 취약점 0건을 확인했으며, 이는 전체 보안 인증이 아닙니다. [APK 보안 검증 범위와 남은 배포 조건](../mobile/readme.md#android-보안-기준과-배포-검사)을 확인하세요.

1. 개발용 HTTPS 서버와 실제 Android·iPhone을 연결하고 앱 종료/복원·만료·오프라인 로그아웃을 확인.
2. 모바일 회원가입·전화번호 인증 화면 이식. 실제 SMS 공급자 연결 상태와 개발용 번호 안내 유지.
3. 수집 원문의 공개 범위를 확정하고 공고 데이터 연결을 완료. 공고 저장→기본 프로필→추천 순서로 후속 이식.
4. TalkBack/VoiceOver·큰 글씨·작은 화면·태블릿·키보드·뒤로 가기 검증.
5. 운영 API·앱 식별자·서명·개인정보/계정 관리·스토어 자료를 확정하고 내부 배포.

실행·함수 계약·검증 명령은 [모바일 README](../mobile/readme.md), 서버 계약은 [API 관리대장](../../api-management.md)을 따릅니다.
