# 2026-10-08 UI 색상 정리

이전 초록색 테마의 직접 지정값을 사용자 웹과 모바일 앱에서 정리했습니다. 화면별 배경·문구·경계·장식의 역할에 따라 색상을 선택합니다.

| 역할 | 색상/토큰 | 적용 예 |
| --- | --- | --- |
| 주요 동작·선택 | `--accent` #0068b7 | 버튼, 선택 질문, 탭 |
| 일반 안내·기준값 | `--surface-muted` #f3f5f8, `--ink`, `--muted` | 중위소득 금액, 100% 기준, 안내문, 지역 범위, 상시 공고 |
| 입력 경계 | `--border-strong` #b5c2cf, `--line` | 검색창, 주소 검색, 질문 입력 |
| AI 상담·추천 설명 | `--assist-accent` #695491, `--assist-soft` #f3eff8 | 상담 메뉴, 추천 이유, 상세 안내 |
| 건강·돌봄 분야 | `--health-accent` #a04457, `--health-soft` #fbf0f3 | 우리 동네 건강서비스 아이콘 |
| 완료·기준 이내 | `--success` #286143, `--success-soft` #eff6f1 | 휴대전화 인증, 저장 성공, 계산 항목의 기준 이내 |
| 마감 주의 | `--warning` #854300, `--warning-soft` #fff0df | 오늘 마감·임박 배지 |
| 일반 알림 | #253447 | 공통 토스트 |

`styles.css`가 의미별 토큰을 정의하고 `portal.css`·기능별 CSS·일반/쉬운 화면이 상속합니다. 주요 동작에 쓰던 `--green`은 `--accent`로 이름을 정리했고, 기존 색상 값은 유지합니다. 계산기의 기준 이내 표시와 실제 신청 자격 판정은 별개입니다.

모바일은 기존 테마 객체에 `assist`, `assistBackground`, `overlay`, `overlayLight`를 추가했습니다. 홈 배너의 초록 배경과 보조 글자를 중립색으로, 질문 배경·인용선을 보라색으로, 교육 분야를 인디고색으로 조정했습니다. 웹의 쉬운 화면 대비·경계 규칙은 유지합니다.

브랜드 로고·공식 기관 로고·배너 이미지의 원본 픽셀과 별도 서버 운영 콘솔은 이 사용자 UI 테마의 변경 대상에 포함하지 않았습니다. 미사용 SVG 나침반·favicon에도 예전 장식색이 재등장하지 않도록 새 팔레트를 적용했습니다.

## 검증

- 웹 단위 검사 182개 중 180개가 샌드박스에서 통과했습니다. 로컬 포트 연결이 차단된 전시 QR 검사 2개는 일반 실행 환경에서 다시 실행해 해당 파일 4개 모두 통과했습니다.
- Vite 운영 빌드 통과. 기존 500kB 청크 크기 권고 경고는 유지합니다.
- 기존 중위소득·지역서비스 E2E 16개 통과. PC·모바일, 쉬운 화면, 언어 변경, 입력 보존·지역 필터·실패/빈 결과 표시를 확인했습니다. 지역서비스 응답은 테스트 서버의 카탈로그입니다.
- 모바일 `npm run typecheck`, `npm run lint` 통과. 네이티브 기기 실행이나 APK 생성은 이번 검사에 포함하지 않았습니다.
- Edge 캡처: 1440px PC, 390px 모바일, 320px 쉬운 화면에서 홈·계산기·로그인·전체 공고·챗봇을 수정 전후 확인했습니다. 가로 넘침과 페이지 오류는 없습니다. 공고·인증 응답은 테스트 대역을 사용합니다.
- 새 텍스트/배경 조합의 대비: AI 5.65:1, 성공 6.64:1, 건강 5.45:1, 마감 주의 6.71:1, 중립 안내 4.76:1, 모바일 교육 5.75:1.
- 사용자 웹·모바일 소스의 초록색 직접 지정값은 웹의 `--success`·`--success-soft` 정의에만 남습니다.
- 캡처 위치: `output/color-review-2026-10-08/`.
