# 모바일 상단바와 전체 메뉴

2026-10-08. 토스와 애플의 공식 모바일 사이트에서 로고 옆 메뉴 버튼과 화면 높이를 사용하는 세로 메뉴를 확인하고 복지나침반에 적용했습니다. 참고: [토스](https://toss.im/), [애플](https://www.apple.com/kr/).

1000px 이하에서는 첫 줄에 브랜드·언어 선택·메뉴 버튼, 둘째 줄에 쉬운 화면·로그인(회원은 알림·로그아웃)을 표시합니다. 회원 이름·회원가입·관리자 링크는 전체 메뉴에서 제공합니다. 기존 가로 스크롤 메뉴와 쉬운 화면 메뉴를 숨기고 동일한 모바일 메뉴를 사용합니다. 1001px 이상은 기존 PC 메뉴를 사용합니다.

`MobileNavigation({page, savedCount = 0, user})`는 메뉴 열기 버튼과 native dialog를 반환합니다. `portalSections`를 공유하여 주요 항목·하위 링크·현재 위치·저장 개수를 표시합니다. 메뉴 안에서 세로로 스크롤하고 배경 스크롤은 잠급니다. 링크 선택·Escape·닫기·PC 너비 전환·계정 변경으로 닫히며 native dialog가 초점 제한과 복귀를 담당합니다. 서버 호출은 없습니다. `mobile-header.css`를 마지막에 로드하여 기존 모바일 계정 행과 쉬운 화면 규칙을 대체합니다.

브라우저 확인: 320px에서 한국어·영어·중국어·베트남어·일본어 각각 일반/쉬운 화면의 제어 영역과 같은 행 배치·가로 넘침을 확인했습니다. 모바일 메뉴 열기·AI 하위 링크 이동·Escape 닫기·초점 복귀·배경 스크롤 복원과 1440px PC 전환도 확인했습니다. 자동 E2E 명세는 `mobile-header.spec.js`, `portal-navigation.spec.js`, `header-account-layout.spec.js`에 갱신했으며 이번 작업에서는 실제 브라우저로 검증했습니다.

운영 빌드와 Node 단위 검사는 통과했습니다. 공개 사이트 정적 배포 후 390px에서 헤더 높이 112px, 로그인/쉬운 화면의 행 중심 일치, 페이지 폭 375px ≤ viewport 390px를 확인했습니다. 전체 메뉴에서 AI 비서 대화로 이동해 입력 화면이 표시되는 것도 확인했습니다. 화면 기록은 `output/mobile-header-20261008.png`, `output/mobile-menu-20261008.png`입니다.
