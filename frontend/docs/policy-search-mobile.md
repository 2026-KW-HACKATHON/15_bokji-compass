# 모바일 공고 검색 범위

모바일 공고 목록도 웹과 같은 검색 범위를 사용합니다. `광운대`로 찾을 때 광운대학교 게시판에서 올라온 공고가 필요하면 **게시기관**, 제목과 본문에 광운대가 언급된 공고가 필요하면 **공고 내용**을 선택합니다. **전체**는 두 범위를 함께 검색합니다.

검색 범위 선택은 검색어 입력 바로 아래에 표시하며 쉬운 화면에서도 접지 않습니다. 범위를 변경하면 현재 적용된 검색어와 분야·지역·정렬을 유지하고 첫 페이지를 다시 조회합니다. 쉬운 화면 전환은 범위를 유지하며, 검색 조건 지우기는 검색어를 비우고 범위를 전체로 되돌립니다.

`frontend/mobile/src/features/policies/model.js`의 `policyPath`는 `searchScope`를 받습니다. `organization`과 `content`는 API의 `search_scope`로 전달하고 기본 `all`은 생략합니다. 검색 결과의 범위 해석과 대학 이름 약칭 처리는 서버가 담당합니다. 공고 내용 검색은 제목과 본문의 단어를 찾으므로 ‘우리대학’처럼 학교 이름을 직접 쓰지 않은 안내까지 의미로 분류하지는 않습니다.

구현은 기존 라디오 선택과 필터·페이지 상태를 재사용하며 새 네이티브 의존성을 추가하지 않았습니다. APK 빌드·배포는 수행하지 않았습니다. 앱의 Expo 버전은 `~57.0.26`이며 화면 변경 전에 [Expo SDK 57 문서](https://docs.expo.dev/versions/v57.0.0/)를 확인했습니다.

검증 명령은 `frontend/mobile`에서 `npm.cmd test`, `npm.cmd run lint`, `npm.cmd run typecheck`입니다. API 단위 테스트는 검색 범위와 검색어·분야·지역·커서가 함께 전달되는지, 기본 범위를 생략하는지, 공개 API 요청과 취소가 유지되는지 확인합니다.

2026-10-07 검증에서 전체 단위 테스트 88개와 타입 검사가 통과했습니다. 변경한 화면·모델·테스트 파일의 ESLint도 통과했습니다. 전체 ESLint는 작업 디렉터리의 별도 모바일 의존성 변경 반영 후 재검사에서 통과했으며, 이 변경에서 수정하지 않은 `AppShell.tsx`의 사용하지 않는 `AgentIcon` 경고 1건이 남았습니다.
