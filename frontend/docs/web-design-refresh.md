# 검색 중심 웹 디자인과 서비스 소개

2026-10-07. 사용자가 선택한 가로 내비게이션·중앙 검색 시안을 기존 웹 앱에 적용했습니다.

## 화면과 이동

2026-10-08 로그인 상단바 보정: PC 열 폭은 로그인/언어 전환 사이에 고정하고 메뉴 간격을
줄여 1440px 쉬운 화면에서도 한국어 메뉴 전체를 표시합니다. 1380px 이하에서는 메뉴를
별도 줄에, 480px 이하에서는 계정 메뉴도 별도 줄에 배치합니다. 긴 회원 이름은 말줄임으로
처리해 로그아웃 버튼을 밀어내지 않습니다. 전체 이름은 기존 `title`로 확인할 수 있습니다.
로그인 전후 위치·메뉴 노출·다국어 로그아웃 노출 회귀 검증은
`web/tests/e2e/header-account-layout.spec.js`에서 320·390·768·1180·1280·1440·1446px로 수행합니다.

상단 메뉴의 메인페이지 이름은 `홈`입니다. 경로는 기존 `#home`을 유지하며, 향후 대화형 기능의 이름과 구분합니다.

- `#home`: 지역과 검색어를 입력하거나 분야를 선택하면 실제 `#explore`로 이동합니다. `q`, `region`, `category` 해시 쿼리는 새로고침과 뒤로가기에서도 유지됩니다. 지역의 전체 값은 기존 API 계약인 `전국`입니다.
- 홈은 서버가 반환한 공고만 표시합니다. 추천 이유, 신청 기간, 공식 조회수·예산 지표, 저장 및 상세 보기를 유지합니다. 빈 결과에는 분야별 탐색을 제공하며 공고를 만들어 채우지 않습니다. 서버 안내도 보존합니다.
- `#guide`: 상단 메뉴 이름은 `서비스 소개`입니다. 제품 소개 형태로 공고 찾기, 맞춤 추천, AI 대화·챗봇, 저장·일정, 쉬운 화면, 공식 조건 확인·계산기를 설명합니다. 시연 데이터에는 예시 표시가 있고 실제 공고와 분리됩니다.
- 가로 메뉴는 작은 화면에서 수평으로 스크롤되며 모든 페이지에 접근할 수 있습니다. 헤더 높이는 ResizeObserver로 측정해 안내 페이지의 고정 목차 위치에 반영합니다.
- 안내 페이지는 별도 청크로 지연 로딩합니다. 모션 감소 설정에서는 스크롤 등장 효과를 끕니다.

## 구현 진입점

- `web/src/app/App.jsx`: 해시 경로, 검색 조건 전달, 공통 헤더, 쉬운 화면, 가이드 CTA 조립.
- `web/src/app/portal.css`: 선택 시안의 공통 레이아웃, 홈, 반응형 보정. `main.jsx`에서 기존 스타일 다음으로 로딩합니다.
- `AssistantHome({onSearch, onGuide, ...})`: `onSearch({query, region, category})`로 탐색을 요청합니다. 다른 저장·상세·추천 콜백 계약은 유지합니다.
- `PolicyExplorer({initialQuery, initialRegion, initialCategory, ...})`: 초기 조건을 검증한 뒤 검색과 선택 필드에 반영합니다. 경로 조건이 바뀌면 App이 재마운트합니다.
- `web/src/features/guide/`: GuidePage와 전용 스타일, 상세 호출 계약은 해당 폴더의 readme.md 참고.

## 문구

‘소진률 → 소진율’, ‘이 공고에 질문하기 → 이 공고에 대해 질문하기’를 포함해 추천 정보 부족, 검색 범위, 달력, 프로필 입력, 계산 도움말을 다듬었습니다. 공식 공고 원문과 서버 생성 답변은 의미를 임의로 바꾸지 않고 전달합니다. 실제 생성 문장의 품질은 별도 응답 사례가 있을 때 점검해야 합니다.

## 2026-10-08 서비스 소개 모션 보완

- `이용 안내`를 `복지나침반 소개`로 변경했습니다. 내부 목차와 로딩 문구도 통일했습니다. 모바일에서는 현재 페이지의 메뉴가 가로 스크롤 영역 안에 보이도록 경로·화면 폭 변경 시 위치를 조정합니다.
- 공고 찾기는 검색 문구 → 분야 → 공고 예시 → 조건 안내, 맞춤 추천은 프로필 → 정보 칩 → 조건 비교 → 추천 공고 → 추천 이유를 순서대로 보여줍니다. 첫 진입 시 각각 2.8초/3.6초 동안 한 번 재생하며 `다시 보기`로 재생할 수 있습니다.
- 클릭·키보드 진입 시 연출을 종료해 즉시 조작할 수 있습니다. 선택한 분야는 재생 후에도 유지하고 결과 전환에만 짧은 움직임을 적용합니다. 동작 줄이기 설정은 실행 중 변경도 반영합니다.
- `useGuideSequence(duration)`의 호출과 반환 계약은 `web/src/features/guide/readme.md`에 기록했습니다. 추가 런타임 의존성은 없습니다.
- 검증: 공고 탐색·소개 페이지 이동·320px 쉬운 화면·모션·수동 선택·키보드·동작 줄이기 브라우저 검사 12개 통과(초기 11개, 모바일 서브픽셀 반올림 허용치를 적용한 재검증 1개). 프로덕션 빌드 통과. 현재 전체 앱의 메인 청크 크기 경고는 남아 있으며 소개 페이지는 별도 청크를 유지합니다.

## 2026-10-08 AI 대화와 챗봇 소개 추가

- 메뉴·내부 목차 제목·로딩 문구의 최종 이름은 `서비스 소개`입니다. 맞춤 추천 다음에 `AI 대화` 목차와 제품 소개 구간을 추가했습니다.
- 대화 예시는 필요한 상황을 말하고 추가 정보를 확인한 뒤 관련 지원·미확인 조건·직접 기록한 신청 상태를 모아보는 흐름입니다. 실제 상담 요청이나 개인정보 저장 없이 페이지 안에서만 재생합니다.
- `AI 복지비서 시작하기`는 기존 `#assistant` 화면으로 이동합니다. `챗봇 열어보기`는 소개 페이지에서 기존 공통 챗봇을 열며 닫으면 본문 버튼으로 초점이 돌아갑니다. 이를 위해 `FloatingAssistant.hideLauncher`는 아이콘만 숨기고, 로그인·가입·관리자·상세 모달의 기존 `blocked` 제어는 유지합니다.
- 생활 상담과 공고 질문은 로그인 후 이용하고, 확인한 정보는 별도 저장 동의 후 계정에 보관한다는 실제 기능 경계를 설명합니다. 기관의 신청 결과 자동 추적이나 기기 간 대화 복원 등 미구현 기능을 약속하지 않습니다.
- 검증: 소개·탐색·모션 브라우저 검사 18개와 기존 챗봇 회귀 검사 4개 통과. 데스크톱 1440px, 모바일 390px·320px에서 새 섹션을 캡처했고 가로 넘침과 페이지 오류가 없었습니다. 프로덕션 빌드 통과(기존 메인 청크 크기 경고 유지).
