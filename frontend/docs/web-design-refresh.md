# 검색 중심 웹 디자인과 이용 안내

2026-10-07. 사용자가 선택한 가로 내비게이션·중앙 검색 시안을 기존 웹 앱에 적용했습니다.

## 화면과 이동

상단 메뉴의 메인페이지 이름은 `홈`입니다. 경로는 기존 `#home`을 유지하며, 향후 대화형 기능의 이름과 구분합니다.

- `#home`: 지역과 검색어를 입력하거나 분야를 선택하면 실제 `#explore`로 이동합니다. `q`, `region`, `category` 해시 쿼리는 새로고침과 뒤로가기에서도 유지됩니다. 지역의 전체 값은 기존 API 계약인 `전국`입니다.
- 홈은 서버가 반환한 공고만 표시합니다. 추천 이유, 신청 기간, 공식 조회수·예산 지표, 저장 및 상세 보기를 유지합니다. 빈 결과에는 분야별 탐색을 제공하며 공고를 만들어 채우지 않습니다. 서버 안내도 보존합니다.
- `#guide`: 제품 소개 형태의 이용 안내입니다. 공고 찾기, 맞춤 추천, 저장·일정, 쉬운 화면, 공식 조건 확인·계산기 안내를 제공합니다. 시연 데이터에는 예시 표시가 있고 실제 공고와 분리됩니다.
- 가로 메뉴는 작은 화면에서 수평으로 스크롤되며 모든 페이지에 접근할 수 있습니다. 헤더 높이는 ResizeObserver로 측정해 안내 페이지의 고정 목차 위치에 반영합니다.
- 안내 페이지는 별도 청크로 지연 로딩합니다. 모션 감소 설정에서는 스크롤 등장 효과를 끕니다.

## 구현 진입점

- `web/src/app/App.jsx`: 해시 경로, 검색 조건 전달, 공통 헤더, 쉬운 화면, 가이드 CTA 조립.
- `web/src/app/portal.css`: 선택 시안의 공통 레이아웃, 홈, 반응형 보정. `main.jsx`에서 기존 스타일 다음으로 로딩합니다.
- `AssistantHome({onSearch, onGuide, ...})`: `onSearch({query, region, category})`로 탐색을 요청합니다. 다른 저장·상세·추천 콜백 계약은 유지합니다.
- `PolicyExplorer({initialQuery, initialRegion, initialCategory, ...})`: 초기 조건을 검증한 뒤 검색과 선택 필드에 반영합니다. 경로 조건이 바뀌면 App이 재마운트합니다.
- `web/src/features/guide/`: GuidePage와 전용 스타일, 상세 호출 계약은 해당 폴더의 readme.md 참고.

## 문구

‘소진률 → 소진율’, ‘이 공고에 질문하기 → 이 공고에 대해 질문하기’를 포함해 추천 정보 부족, 검색 범위, 달력, 프로필 입력, 계산 도움말을 다듬었습니다. 공식 공고 원문과 서버 생성 답변은 의미를 임의로 바꾸지 않고 전달합니다. 실제 생성 문장의 품질은 별도 응답 사례가 있을 때 점검해야 합니다.
