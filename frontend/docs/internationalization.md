# 웹·앱 다국어 UI와 공고 번역

2026-10-07. 담당: 프론트엔드. 사용자가 선택한 한국어·영어·중국어(간체)·베트남어·일본어를 웹과 Expo 모바일에 적용합니다.

공통 사전은 `packages/core/src/i18n/`, 웹 context/선택기는 `web/src/shared/i18n/`, 앱 context/저장/선택기는 `mobile/src/i18n/`에 있습니다. API enum이나 저장 프로필의 구조는 바꾸지 않고 렌더링만 번역합니다.

## 지원 동작

- 웹 헤더와 모바일 공통 상단/계정 화면에서 언어를 선택합니다. 지원 언어 이름은 한국어, English, 中文, Tiếng Việt, 日本語로 표시합니다.
- 저장한 선택값이 자동 언어 감지보다 우선하며 언어 변경은 현재 화면에 즉시 반영합니다. 저장이 차단돼도 현재 세션에서는 변경할 수 있습니다.
- 홈, 공고 검색·상세의 UI, 캘린더, 계정·추천 정보, 회원가입·로그인, 계산기, 안내 등의 정적 문구를 사전으로 관리합니다. 금액 단위는 원화로 유지하며 날짜·숫자·화폐 표시에는 해당 언어의 Intl 표현을 사용합니다.
- 문장 키의 변수는 `{name}` 방식으로 전달합니다. 이름·주소·검색어 같은 입력값과 API 필터·저장값은 유지합니다. 공고 번역은 UI 사전과 별도 서버 계약으로 처리합니다.

## 공개 공고 번역

한국어 외 언어에서는 공개 공고의 제목·요약·본문·대상·지원 내용·신청 방법·문의처·추가 조건·원문 항목을 `GET /v1/policies/{id}/translation?language=en|zh|vi|ja`로 조회합니다. 웹·앱 목록·추천·상세·캘린더 및 상담의 공고 제목에 표시하며, 사용자 질문·프로필·주소는 번역 요청에 보내지 않습니다. 신청 링크·공고 ID·개정 ID·지역·분야·날짜 필터 등 원래 데이터는 유지하고 번역된 표시값으로 저장·검색·신청하지 않습니다.

번역 대기·실패 시 한국어 원문과 상태를 표시하고 재시도를 제공합니다. 상세에는 원문/번역 전환이 있습니다. 언어·공고 변경 후 늦게 도착한 결과를 이전 화면에 적용하지 않고, 사용자가 떠난 화면의 아직 시작하지 않은 요청은 취소합니다. 웹 긴 목록은 화면 근처의 공고부터 요청합니다. 클라이언트 요청은 순차 실행하며 최대 128개 대기·100개 결과·30초 메모리 캐시로 제한합니다.

서버는 기존 Codex CLI와 `CODEX_MODEL` 설정을 사용해 공개 공고 표시 필드만 번역합니다. 별도의 공급자나 API 키는 추가하지 않았습니다. 공고·개정·원문 해시·언어·프롬프트 버전별 결과를 DB에 저장하고 공개 상태와 개정을 재확인합니다. JSON 구조, 숫자·날짜·URL·이메일 보존을 검증하며 번역 결과를 신청 자격 확정으로 사용하지 않습니다. 1개 서버 프로세스당 생성 1건, 호출당 최대 60초, DB에 기록하는 UTC 일일 생성 상한 기본 100회이며 실패한 호출도 한도에 포함합니다. 캐시 적중은 생성 한도를 사용하지 않습니다.

운영 적용 전에 공고 DB의 명시적 저장 초기화로 `011_policy_translations.sql`을 적용하고 서버의 Codex CLI 설치·로그인·모델 접근을 확인해야 합니다. `POLICY_TRANSLATION_ENABLED`, `POLICY_TRANSLATION_MAX_INPUT_CHARS`, `POLICY_TRANSLATION_DAILY_CALLS` 설정과 초기화 방법은 [서버 번역 모듈](../../backend/app/modules/policy_translation/readme.md)을 참고하세요. 요청에서 테이블을 생성하지 않습니다. 새 공급자를 연결하지 않더라도 기존 모델 호출에는 기존 이용 한도가 적용됩니다.

AI 상담의 자유 답변·서버의 검색 근거·일부 운영자/보관기간 설명, 카카오 주소검색 화면과 관리자 콘솔은 현재 원문입니다. 비한국어 화면에 AI 상담 답변의 한국어 제공과 공식 공고 원문 확인을 안내합니다.

## 유지보수

2026-10-08: 독립 AI 복지비서 페이지의 신규 제목·설명·대화 선택지·요약 카드·상태·상세 메뉴와 챗봇 이어보기 안내를 `assistantMessages.js` 및 `t()` 렌더링에 연결했습니다. 상단 AI 복지비서·서비스 소개 메뉴와 로딩 상태도 같은 사전을 사용합니다. `assistant-i18n.spec.js`는 네 외국어 메뉴 이동·재접속, UI 누락, 프로필 수정값·상담 초안 보존과 가로 넘침을 PC/모바일에서 검사합니다.

1. 새 UI 문구는 담당 사전에 한국어 키와 네 외국어 번역을 함께 추가합니다.
2. React 컴포넌트는 `useI18n().t()`를 렌더링에서 사용합니다. API 요청값·입력 state·필터 비교에는 번역값을 쓰지 않습니다.
3. 공통 사전·번역 응답 검증·캐시·취소 단위 테스트와 웹 언어 전환·공고 번역 E2E를 실행합니다. 모바일은 타입 검사·lint·단위 테스트와 Android/iOS export를 함께 확인합니다.
4. 긴 문장을 한국어식 조각 단위로 이어 붙이지 않고 변수 포함 문장으로 만듭니다.

함수 계약과 반환값은 [공통 번역](../packages/core/src/i18n/readme.md), [웹 번역](../web/src/shared/i18n/readme.md)을 참고하세요. 검증 결과는 [프론트엔드 작업 기록](worklog.md)에 기록합니다.
