# 우리 동네 복지 페이지

## 2026-10-08 지역 확장과 실제 수집

기본 중점 지역을 노원구·월계1동으로 정하고 프론트 고정 목록을 공개 `/v1/local-services` API로 옮겼습니다. 회원 주소나 추천 지역은 중점 기본값보다 우선합니다. 지역 미입력 시에만 월계1동을 보여줍니다.

| 수집 지역 | 서비스 수 |
| --- | ---: |
| 서울 노원구 | 8 |
| 서울 도봉구 | 2 |
| 서울 강북구 | 1 |

| 서울 중랑구 | 1 |
| 경기 수원시 | 2 |

| 인천 광역 | 1 |

총 20건. 월계1동 직접 연결 4건은 주민센터 복지 상담·꿈꾸는작은도서관·월계문화 아이휴센터·달빛마실 아이휴센터입니다. 월계도서관은 월계2동으로 공식 시설표에서 확인했으며 월계1동으로 오분류하지 않습니다.

서비스 스키마는 `coverage`(전국·시도·시군구·동 복수 범위), `focusAreas`(동과의 확인된 관계), `neighborhoodType`(행정동/법정동), `audience`(실제 이용자격)를 분리합니다. `sourceUrl/sourcePublishedAt/checkedAt/evidence`로 원문·게시일·확인일·근거를 보존하고 알 수 없는 날짜는 null로 둡니다. `availableUntil`에 공식 종료일을 기록하면 당일까지 공개하고 다음 날 목록·통계에서 제외합니다. 현재 수원 2건은 2026-12-31까지입니다.

전국 17개 시도, 시→구 계층, 세종의 구 없는 구조, 같은 이름의 다른 지역을 처리합니다. 전국·세종 서비스 레코드의 계약은 합성 테스트로 검증하며 실제 수집 건수에 포함하지 않습니다. 등록 지역 드롭다운과 구·광역 포함/해당 동 중심 범위를 제공합니다. 시도만 입력해도 해당 시도 수집 자료를 탐색할 수 있습니다.

자료는 `backend/reference/local_services/services/*.json`에 저장합니다. 새 지역은 동일 스키마의 검증 자료를 추가하면 되고 프론트 코드를 변경할 필요가 없습니다. 서버는 매 요청 출처·중복·날짜·범위 검증을 수행하며 손상은 503, 미수집은 정상 빈 목록으로 구분합니다. 상세 주소·우편번호·번지를 공개 API나 URL/브라우저 저장소로 보내지 않습니다.

이는 공식 자료를 사람이 검토한 초기 수집이며 전국 전수 수집·자동 크롤러·정기 원문 갱신·거리 계산·실시간 예약은 구현하지 않았습니다. MySQL 적재가 아닌 검증된 파일 카탈로그입니다. [백엔드 설계와 추가 절차](../../backend/docs/local-services.md), [노원 출처](../../backend/docs/local-services-nowon-sources.md), [타 지역 출처](../../backend/docs/local-services-other-sources.md).

확장 검증 결과: 백엔드 지역서비스·OpenAPI 36개, 실제 API 기반 웹 E2E 데스크톱·모바일 8개, 최종 응답계약 단위 2개와 웹 빌드 통과. 전체 웹 테스트는 154개 중 153개 통과·1개 실패이며, 실패는 지역복지와 독립된 `count-choices.test.js`의 `groupFrom` 접근입니다. 자료검증 CLI는 총20건·명시 시군구7곳과 부산/인천 광역 범위를 확인했습니다.

아래는 최초 3건 구현 기록이며 위 확장 내용으로 데이터·범위 계약을 대체합니다.

다른 지역과 비어 있는 분야는 미수집 상태로 안내합니다.

## 동작과 경계

- 지역 선택은 시·도와 시·군·구를 함께 입력합니다. 도로명 주소에서 동을 추측하지 않습니다.
- 동을 입력해도 결과 범위는 해당 시·군·구입니다. 시설과 운행권역은 카드에 별도로 표시합니다.
- 서비스 지역 탐색과 이용 자격은 다릅니다. 거주 제한·나이·예약은 각 공식 안내가 기준입니다.
- ‘지역 관련 공고 찾기’는 `#explore?q=시군구&region=시도`로 이동합니다. 기존 API의 텍스트 검색이며 해당 구 주민의 이용 가능성을 확정하지 않습니다.
- 정확한 주소·상세 주소를 추가 저장하거나 검색 URL에 넣지 않습니다. 지역·분야 선택은 페이지 왕복 동안 메모리에서 유지하고 로그인 계정 변경/로그아웃 시 초기화합니다.
- 서비스 본문은 한국어 공식 자료 요약입니다. UI는 기존 5개 언어 체계를 사용하며 외국어에서 본문 언어 안내를 표시합니다.
- 일반 화면은 화면 폭에 따라 1~3열, 쉬운 화면은 1열입니다. 지역·분야는 화면 모드와 언어를 바꿔도 유지합니다.

## 구현과 검증

`web/src/features/local`에 화면·카탈로그·순수 지역 모델을 분리했습니다.
호출 계약은 [폴더 README](../web/src/features/local/readme.md)에 기록했습니다.
모델 테스트는 지역 동명이름 구분·주소 최소화·도로명 동 추정 방지 등을 검증합니다.
E2E는 회원/비회원 진입, 분야 전환, 미수집 지역, 공고 검색 연결, 로그아웃,
320px 쉬운 화면과 언어 전환을 확인합니다.

검증 결과: 전체 Node 테스트 149개와 빌드 통과. 새 페이지 및 공통 메뉴 E2E는
데스크톱·모바일 14개 통과했습니다. 테스트 API 대역으로 UI 흐름을 확인했으며
공식 기관의 실제 예약·탑승 및 운영 서버 배포는 수행하지 않았습니다.

후속 확장: 지역별 공식 서비스 수집 및 검수 저장소, 시설 좌표와 이동 반경,
운행 노선·정류장 상세는 별도 데이터와 계약이 필요합니다.
