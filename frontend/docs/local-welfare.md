# 우리 동네 복지 페이지

2026-10-08 · 프론트엔드

생애 단계보다 사용자의 생활지역을 먼저 탐색하는 `#local` 페이지를 추가했습니다.
주 메뉴의 ‘우리 동네 복지’와 홈의 ‘동네 복지 둘러보기’에서 진입합니다.
회원 기본 주소의 시·도/시·군·구를 사용하며 비회원도 직접 지역을 입력할 수 있습니다.
집 외에 직장·학교 주변을 검색해도 회원 주소는 변경되지 않습니다.

공식 자료가 확인된 노원구 서비스 3개로 시작합니다. 무료버스(노원행복버스),
월계평생건강관리센터, 월계도서관을 이동·건강·문화 분야에서 볼 수 있습니다.
이용 지역·대상·요금·방법·원문·확인일을 제공합니다. 세부 [출처 기록](local-welfare-sources.md).
카탈로그는 수동으로 검증한 안내이며 전국 수집이나 실시간 운행·예약 조회가 아닙니다.
다른 지역과 비어 있는 분야는 미수집 상태로 안내합니다.

## 동작과 경계

- 지역 선택은 시·도와 시·군·구를 함께 입력합니다. 도로명 주소에서 동을 추측하지 않습니다.
- 동을 입력해도 결과 범위는 해당 시·군·구입니다. 시설과 운행권역은 카드에 별도로 표시합니다.
- 서비스 지역 탐색과 이용 자격은 다릅니다. 거주 제한·나이·예약은 각 공식 안내가 기준입니다.
- ‘지역 관련 공고 찾기’는 `#explore?q=시군구&region=시도`로 이동합니다. 기존 API의 텍스트 검색이며 해당 구 주민의 이용 가능성을 확정하지 않습니다.
- 정확한 주소·상세 주소를 추가 저장하거나 검색 URL에 넣지 않습니다. 지역·분야 선택은 페이지 왕복 동안 메모리에서 유지하고 로그인 계정 변경/로그아웃 시 초기화합니다.
- 서비스 본문은 한국어 공식 자료 요약입니다. UI는 기존 5개 언어 체계를 사용하며 외국어에서 본문 언어 안내를 표시합니다.
- 일반 화면은 화면 폭에 따라 1~3열, 쉬운 화면은 1열입니다. 지역·분야는 화면 모드와 언어를 바꿔도 유지합니다.

## 구현과 검증

`web/src/features/local`에 화면·카탈로그·순수 지역 모델을 분리했습니다.
호출 계약은 [폴더 README](../web/src/features/local/readme.md)에 기록했습니다.
모델 테스트는 지역 동명이름 구분·주소 최소화·도로명 동 추정 방지 등을 검증합니다.
E2E는 회원/비회원 진입, 분야 전환, 미수집 지역, 공고 검색 연결, 로그아웃,
320px 쉬운 화면과 언어 전환을 확인합니다.

검증 결과: 전체 Node 테스트 149개와 빌드 통과. 새 페이지 및 공통 메뉴 E2E는
데스크톱·모바일 14개 통과했습니다. 테스트 API 대역으로 UI 흐름을 확인했으며
공식 기관의 실제 예약·탑승 및 운영 서버 배포는 수행하지 않았습니다.

후속 확장: 지역별 공식 서비스 수집 및 검수 저장소, 시설 좌표와 이동 반경,
운행 노선·정류장 상세는 별도 데이터와 계약이 필요합니다.
