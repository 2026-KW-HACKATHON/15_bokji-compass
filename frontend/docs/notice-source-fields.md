# 공고 상세 JSON 표시 보완 (2026-10-08)

공고 상세에서 근거 법령·문의처가 원천 JSON 배열로 노출되는 경로를 수정했습니다.
서버의 공통 표시 계층에서 법령명, `기관명: 전화번호`, 신청 단계, `파일명: URL`,
관련 링크를 줄별 문자열로 제공하고 `.policy-detail dd`에서 줄바꿈을 유지합니다.
긴 파일 주소도 좁은 화면에서 줄을 나누어 표시합니다.

특정 제목에만 적용하지 않아 같은 형태의 다른 공고와 향후 수집 자료에도 적용됩니다.
원문·신청 캘린더·인용 근거는 유지합니다. 웹/모바일 공통 문자열 API를 그대로 사용하며
저장·캘린더·추천·번역에도 정제된 표시 값이 전달됩니다.

연결된 DB의 최신 공개 공고 562건을 읽기 전용으로 확인했고 20건의 법령/문의처/신청 방법과
17건의 첨부 파일에서 같은 구조를 찾았습니다. 총 77개 항목을 변경된 서버 투영에 통과시킨
결과 JSON 객체/배열로 남은 항목은 없었습니다. [서버 변환·검증 계약](../../backend/docs/notice-source-fields.md).

`web/tests/e2e/policy-source-fields.spec.js`는 합성 복지로 데이터를 실제 `card(full=True)`로
변환해 PC와 320px 모바일의 일반/쉬운 화면에 전달합니다. 법령·문의처·신청 절차·이의 신청·
파일 주소·관련 링크, 원천 키 미노출, 키보드 상세 열기/닫기, 줄바꿈과 가로 넘침을 확인합니다.
기존 `policy-source.spec.js`의 안전한 원문/신청 링크와 한글 라벨도 함께 검증합니다.
실제 모바일 앱 OS와 실행 중인 운영 서버의 배포 검증은 포함하지 않습니다.

검증 결과: 웹 단위 전체와 최종 Vite 빌드 통과. PC/모바일 브라우저 6개 통과.
실제 정제된 법령명·기관과 전화번호·신청 단계·파일 URL의 스크린샷도 확인했습니다.
백엔드 관련 회귀 331개 통과·3개 생략, 최종 표시/원문 보존 55개와 Ruff 통과.
브라우저 검증은 전용 로컬 포트 5199/8027의 격리 서버와 합성 응답을 사용했습니다.
