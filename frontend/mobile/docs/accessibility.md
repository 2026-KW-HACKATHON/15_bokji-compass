# 쉬운 화면 접근성

2026-10-08. [Apple Human Interface Guidelines — Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)의 글자 확대, 대비, 색 이외의 상태 표현, 충분한 터치 영역, 익숙한 조작과 단순한 정보 구성을 적용합니다. iOS 전용 화면을 복제하지 않고 기존 Expo/React Native 탐색과 데이터 흐름을 유지합니다.

## 구현

- `LocalizedText.tsx`는 쉬운 화면의 본문과 보조 문구를 최소 20sp, 줄 간격을 글자 크기의 최소 1.5배로 맞춥니다. 공통 제목은 28sp이고 OS 글자 확대를 제한하지 않습니다. 원문·번역 경계는 유지합니다.
- 공통 버튼·선택·펼침·모드 전환은 쉬운 화면에서 최소 60dp 높이를 사용합니다. 입력칸은 최소 64dp이며 시스템 글자 배율에 따라 커집니다. 포커스에는 굵은 테두리를 표시합니다. 비활성 버튼은 글자 전체를 흐리게 만들지 않습니다.
- 모드·금융 선택·저장 동의·알림 설정은 라벨 전체를 누를 수 있습니다. 스위치는 위치와 체크, 선택 항목은 테두리와 체크, 하단 현재 탭은 밑줄로 상태를 구분합니다. 역할과 선택·확장·비활성 상태를 보조 기술에 전달합니다.
- 하단 탭 문구는 잘라내지 않고 줄바꿈하며 글자 배율에 따라 높이를 확보합니다. 홈 분야는 좁은 폭 또는 큰 글자에서 한 열이 됩니다. 계산 단계는 쉬운 화면에서 가로 스와이프 없이 볼 수 있도록 줄바꿈합니다. 공고의 추가 검색 조건은 펼쳐서 선택하고 현재 분야·지역을 표시합니다.
- 쉬운 화면의 챗봇 진입은 화면 마지막의 일반 버튼과 전체 메뉴에서 제공합니다. 떠 있는 버튼이 본문이나 입력을 가리지 않습니다.
- 언어 선택의 지구본 이모지, 가입 동의의 문자 체크 상자, 펼침 기호를 같은 Lucide 아이콘 계열로 통일했습니다. 기능에는 텍스트 라벨을 함께 표시하고 장식 아이콘은 스크린 리더에서 제외합니다. 쉬운 홈의 큰 장식 그림과 챗봇 그림자는 줄였습니다.
- 쉬운 화면의 홈 분야·공고 분야·AI 지원 카드에는 60dp 타일 안의 34dp 아이콘을 사용합니다. 선 두께 2.25, 진한 파랑 `#0068B7`과 옅은 파랑 `#E0F2FE` 배경을 공통 적용하고 홈 분야명은 22sp의 굵은 글자로 구분합니다. 일반 화면의 기존 크기·분야 색상은 유지합니다.
- 공고 제목·대상·기간은 쉬운 화면에서 생략하지 않습니다. 상세의 긴 지원 내용은 전체 보기로 접근합니다. 금융 입력의 빈 값·0원·모름과 명시적인 계정 저장 동의는 그대로 유지합니다.

## 확인 범위

`npm run typecheck`, `npm run lint`, `npm test`로 타입·정적 규칙·기존 계약 회귀를 확인합니다. 브라우저 확인과 네이티브 TalkBack/VoiceOver 검증은 별개입니다. APK 재빌드·기기 설치·스토어 배포를 포함하지 않습니다.

기기에서 확인할 흐름:

1. 쉬운 화면을 켜고 글자를 200% 이상 확대해 홈·공고·계산기·AI 비서·내 계정을 이동합니다. 모든 하단 라벨과 현재 탭을 확인합니다.
2. 320/390/430dp 폭과 가로 화면에서 언어 선택·메뉴·챗봇을 열고 닫습니다. 내용이 가려진 경우 스크롤로 마지막 조작까지 접근할 수 있어야 합니다.
3. 계산기의 빠른 확인·상세 계산, 가구원 직접 입력, 0원/모름 선택, 오류 수정, 단계 이동, 저장 동의를 확인합니다.
4. 공고 조건을 펼쳐 분야·지역을 선택하고 상세에서 긴 지원 내용을 펼칩니다. 모드를 전환해도 입력과 선택 조건이 유지되는지 확인합니다.
5. TalkBack/VoiceOver와 외부 키보드에서 역할·라벨·선택 상태·확장 상태와 메뉴 포커스 이동을 확인합니다. 운영 데이터·계정 정보를 테스트용으로 변경하지 않습니다.

기술 근거: [Expo SDK 57](https://docs.expo.dev/versions/v57.0.0/), [React Native Text](https://reactnative.dev/docs/text), [React Native Accessibility](https://reactnative.dev/docs/accessibility).
