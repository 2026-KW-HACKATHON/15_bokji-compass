# 모바일 챗봇과 전체 메뉴

2026-10-02. 웹 `PolicyQuestion`의 공개 공고별 회원 질문 기능을 앱으로 이식합니다. 일반 대화·실시간 상담원 연결·추천 모델을 새로 제공하는 기능은 아닙니다.

## 사용 흐름

- 공통 화면 오른쪽 아래 상담원 아이콘에서 챗봇을 엽니다. 키보드가 표시되는 동안 아이콘은 숨기며, 화면 하단에는 아이콘을 피해 마지막 콘텐츠를 스크롤할 여백을 둡니다.
- X는 ‘챗봇 기능을 끄시겠습니까?’ 확인창을 표시합니다. 취소하면 현재 상담을 유지하고, 끄면 질문/답변/진행 요청을 제거한 뒤 재진입 위치를 안내합니다.
- 오른쪽 위 ≡ 전체 메뉴의 ‘챗봇 다시 켜기’로 복구합니다. 켜진 상태에서는 ‘챗봇 상담’으로 표시합니다. 메뉴에서 홈·공고·중위소득 계산기·내 계정·쉬운 화면 전환을 사용할 수 있습니다.
- ‘접기’와 Android 뒤로 가기는 상담창만 닫으며 아이콘은 유지합니다. 닫힌 상담 내용은 메모리에서 제거됩니다. 켜기/끄기 설정은 앱 실행 중에만 유지합니다.
- 공고 상세의 ‘이 공고에 챗봇 질문하기’는 해당 개정을 바로 선택합니다. 일반 진입에서는 로그인 후 공고 검색·페이지 이동으로 상담할 공고를 고릅니다.

## 웹과 동일한 API와 안내

| 기능 | 요청·처리 |
| --- | --- |
| 준비된 질문 | `GET /v1/assistant/faqs?revision_id=...`, 15초 제한 |
| 선택형 답변 | 받은 FAQ를 즉시 표시, 추가 요청/LLM 호출 없음 |
| 직접 질문 | `POST /v1/assistant/questions`, `{revision_id, question}`, 70초 제한 |
| 인증 | 앱은 Bearer, 웹은 쿠키. 같은 회원 접근 경계 사용 |
| 답변 표시 | 준비된 안내/공고에 따른 안내, 원문 인용 펼침, 추가 확인사항, 기관 확인 안내 |
| 응답 검증 | 개정 일치, preview=false, eligibility_decided=false, grounded에는 인용 필수 |
| 오류 | FAQ 재시도, 빈 공개 목록, 404/401/503/시간 초과 구분. 서버 내부 오류문은 표시하지 않음 |

공고 모델은 `revisionId`를 보존하며 유효한 개정이 없으면 질문을 보내지 않습니다. 질문은 1~2,000자이고 회원의 지역·연령대는 웹과 마찬가지로 서버가 구성합니다. 질문에 금융 초안·이름·전화번호를 자동 첨부하지 않습니다.

## 상태·보안

질문·답변은 메모리에만 유지합니다. 계정/토큰/개정 변경, 창 닫기, 기능 끄기, 백그라운드 전환 시 이전 답변을 재사용하지 않습니다. 화면 제거 및 FAQ 선택 시 AbortController로 진행 질문을 취소하며 늦은 응답이 새 선택을 덮어쓰지 못하게 합니다. 취소는 클라이언트 표시/대기를 끝내며 이미 서버에서 시작한 모델 실행 자체의 중단을 보장하지 않습니다.

응답은 일반 Text로만 렌더링하며 HTML/WebView를 사용하지 않습니다. 질문 API도 기존 redirect:error·쿠키 미사용·보안 저장소 정책을 유지합니다. 상담/메뉴/확인창은 새로운 네이티브 Dialog 창을 만들지 않고 기존 보호 창 내부에서 표시하므로 Android FLAG_SECURE 경계를 유지합니다. 새로운 네이티브 모듈·권한·외부 상담 SDK는 추가하지 않았습니다.

웹 미리보기는 모달 접근 범위·Tab 포커스 순환·Escape 닫기, Android는 뒤로 가기를 지원합니다. TalkBack/VoiceOver 실사용 검증은 별도로 필요합니다.

## 검증과 서비스 준비 상태

- 모바일 계약/보안 단위 테스트 28개, 타입/린트 통과.
- Android/iOS Hermes 번들 생성 통과. iOS 기기 실행 검증은 별도 필요합니다.
- Android 에뮬레이터에서 상담 진입은 확인했으나 UIAutomator의 `null root node`·덤프 지연으로 닫기/재활성화 전체 자동 검사는 완료하지 못했습니다. 해당 흐름의 브라우저 검증과 구분하며, 네이티브 회귀 통과로 간주하지 않습니다.
- 기존 백엔드 공고 질문·FAQ 테스트 11개 통과(모바일 Bearer·공개 범위·LLM 우회 FAQ 포함).
- 브라우저 320/390/430px에서 X 취소/확정, 재활성화, 메뉴 이동, 로그인, FAQ/직접 질문/인용, 503, 늦은 응답 취소, 종료 후 내용 제거, 로그아웃 검증. 렌더링 오류 없음.
- 기존 홈/쉬운 화면/공고 회귀 통과. 브라우저 답변은 테스트 전용 응답 대역이며 실제 서비스 공고나 AI 응답으로 저장하지 않습니다.
- 현재 로컬 서버 8771은 질문·FAQ 경로를 제공하지만 2026-10-02 조회 시 공개 공고는 0개입니다. 실제 공개 공고를 대상으로 한 생성형 답변의 종단 검증은 아직 수행하지 못했습니다. 직접 질문의 성공은 웹과 동일하게 서버 모델 준비 상태에 따릅니다. 미공개 원문을 자동 공개하지 않습니다.
