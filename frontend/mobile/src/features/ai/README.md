# Android AI 복지비서

2026-10-08. 웹 AI 페이지의 생활정보, 지원 후보, 추가 확인사항, 신청 현황, 새 안내와 대화형 정보 입력을 네이티브 화면으로 제공합니다. 하단 `AI 비서`와 전체 메뉴에서 진입합니다. 공고별 질문을 위한 작은 `챗봇` 창과는 별도 화면입니다.

## 화면과 데이터

- `AiScreen.tsx`: 내 상황 요약과 네 가지 현황, 지원 후보·추가 확인·신청 현황·새 안내, 생활정보 관리.
- `GuidedConversation.tsx`: 시작 질문, 한 단계씩 이어지는 후속 질문, 확인된 사실, 지원 후보와 근거 링크, 명시적 동의 후 저장.
- `ProfileEditor.tsx`: 주거·직업·가구·재난 정보 수정. 모르는 값은 미확인으로 유지하고 저장 및 지속 안내는 직접 선택합니다.
- `overview.js`, `monitoringModel.js`, `dialogueModel.js`: 웹과 같은 집계·응답 검증 규칙. 신청 내역은 비활성 후보의 기록도 보존하며 같은 공고·확인사항을 중복 집계하지 않습니다.
- 일반 화면은 요약 카드와 단계별 펼침을 사용합니다. 쉬운 화면은 큰 글자, 최소 60dp 주 버튼, 명시적인 체크 표시를 유지합니다.

비회원에게 임의의 안내 개수나 시험 데이터를 보여주지 않습니다. 로그인 안내와 기능 설명만 표시합니다.

## API와 상태

웹과 동일한 `/v1/monitoring` 및 `/v1/assistant/dialogue` API를 사용하고, 네이티브 세션의 Bearer 토큰을 전달합니다. 쿠키와 HTTP 리다이렉트는 사용하지 않습니다. API 주소는 공통 런타임 설정을 따르며 릴리스는 `https://bokji.commitnaru.com/api`입니다.

생활정보 저장·대화 결과 저장에 동의를 요구하고, 서버의 확정 여부와 개정 식별자를 검증합니다. 지원 대상 확정을 주장하는 응답, 잘못된 날짜·상태·중복 식별자와 안전하지 않은 근거 링크는 거부합니다. 원문 응답에 포함된 불필요한 개인정보 필드는 화면 모델에서 제외합니다.

대화·편집 초안은 메모리에만 유지합니다. 화면 이탈 시 요청을 취소하고, 계정 변경이나 백그라운드 전환 시 이전 화면 데이터를 폐기합니다. `taskGate.js`는 중복 요청과 취소된 요청의 늦은 응답을 차단합니다. 서버에서 이미 시작된 연산 자체의 중단을 보장하지는 않습니다.

## 검증

`tests/ai-workspace.test.mjs`에서 Bearer 계약, 명시적 동의, 응답 검증, 현황 집계, 계정 변경 중 요청 취소, 중복 저장, 화면 폭·키보드·쉬운 모드별 챗봇 크기를 검사합니다. 백엔드 `test_monitoring_api.py`, `test_assistant_dialogue_api.py`는 격리 DB에서 계정 접근과 저장 계약을 검사합니다.

운영 공개 경로는 인증 없이 401을 반환하는 경계까지 확인했습니다. 실제 회원 로그인 후 생성형 답변과 계정 저장의 종단 검증은 별도이며, 계약 검사나 비회원 네이티브 확인으로 대체하지 않습니다.
