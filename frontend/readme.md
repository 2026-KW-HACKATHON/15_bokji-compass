# 프론트엔드
담당: 프론트엔드. 서버에 수집된 공고를 사용자 정보에 따라 개인비서 LLM이 추천하는 서비스를 만듭니다.

- [web/](web/readme.md): React/JavaScript 반응형 웹. 개인비서 홈·공고 검색·태그·저장·내 정보·로그인/가입 폼·쉬운 화면.
- [android/](android/readme.md): 향후 Java 기반 Android 앱. 아직 미구현.
- [ios/](ios/readme.md): 향후 iOS 앱. 언어·프레임워크 미확정.
- [docs/](docs/readme.md): 구조, 서버 계약 제안, 배포, 접근성, 작업 기록.

2026-09-22 기준 개발은 표시된 합성 예시, 운영 빌드는 API 모드가 기본입니다. 공고·LLM 추천 서버 API는 아직 미구현이며 웹 호출자만 준비했습니다. 인증은 입력폼만 있고 저장·전송·로그인 처리는 없습니다. 프론트는 공개 HTTP로만 연결합니다.
