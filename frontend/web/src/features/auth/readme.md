# 웹 회원가입·로그인

2026-10-02: AuthPage({type, onLogin})는 전화번호 없는 일반 가입과 카카오 로그인을 제공합니다. 일반 가입은 SignupWizard의 항목별 단계 입력을 사용하며 일반·쉬운 화면 모두 단계별 검증·초점 이동·입력 보존을 지원합니다. 기존 아이디·비밀번호 로그인은 유지합니다.

카카오 버튼은 서버 kakao/status가 enabled=true일 때 활성화합니다. kakao/start의 고정 카카오 인증 주소로 이동하고 서버 콜백이 기존 회원은 홈, 신규 회원은 #signup?kakao=complete로 돌려보냅니다. 신규 회원은 kakao/pending으로 인증 상태를 확인한 뒤 이름·만 나이·성별·시도만 단계별로 입력하고 가입 즉시 로그인합니다. 전화번호·아이디·비밀번호를 추가로 요구하지 않습니다. 취소/오류/만료 안내와 재시도 버튼을 제공합니다.

authApi.js는 credentials=include, X-Auth-Request: 1, 15초 제한을 사용합니다. 비밀번호·카카오 토큰·시크릿을 브라우저 저장소에 기록하지 않습니다. 기존 App의 /me 세션 복원과 onLogin을 재사용합니다.

[서버 계약](../../../../../backend/app/modules/auth/readme.md), [카카오 개발자 설정](../../../../../backend/docs/kakao-login.md). tests/e2e/auth.spec.js는 실제 일반 가입 API와 대역 기반 카카오 화면을 데스크톱·모바일 크기에서 확인합니다. 실제 카카오 동의 화면 테스트는 앱 설정 후 별도 수행합니다.

2026-10-02: 서버 회원 저장은 MySQL+개인정보 암호화로 전환했으며 웹 HTTP 계약은 유지합니다. Playwright는 APP_ENV=test의 격리 SQLite와 실행별 독립 암호화/HMAC 테스트 키를 사용하며 실제 서버 키를 사용하지 않습니다. [서버 저장 보안](../../../../../backend/docs/member-privacy.md).

공고 기본 승인 방식은 자동 승인입니다. 관리자 목록 응답의 autoPublish가 true이면 검증된 새 공고의 저장 후 자동 공개 안내를 표시합니다. 기존 공고 검토·수동 공개·비공개 기능은 유지합니다.

`AdminPage`의 `PolicyPublication()`은 최고 관리자용 공고 개정 목록과 `공고 검토` 대화상자를 제공합니다. 목록은 10건 단위 API 페이지이며 원문·표시 미리보기·누락 정보·최근 이력을 확인합니다. 검토 체크 후 공개, 공개 중인 개정은 비공개 전환할 수 있습니다. 선택 검토 메모·현재 상태를 `/v1/admin/policies/{revisionId}/publication`에 전송하고 완료 후 목록을 새로 조회합니다. 409는 다시 불러오기, 401/403은 검토 내용 제거·재로그인 안내, 실패는 선택 내용 유지. 계정/화면 종료 시 요청 취소, 변경 중 대화상자 닫기/중복 실행 방지. 공개는 자격 판정 확정이 아닙니다. PC·모바일 검증: `tests/e2e/publication.spec.js`.

`AuthPage({type, onLogin})`는 아이디 로그인 및 `SignupWizard` 회원가입의 진입점입니다. 일반·쉬운 화면 모두 가입 방법 선택 → 아이디 입력·DB 중복확인 → 비밀번호 → 비밀번호 확인 → 이름 → 만 나이 → 성별 → 시도 → 가입 확인 순서로 한 항목씩 진행합니다. 이전 단계로 돌아가거나 화면 모드를 바꿔도 입력값이 유지됩니다. 진행률은 아이디·비밀번호·기본 정보·가입 확인의 4개 묶음으로 표시합니다. 단계 제목과 오류 안내로 초점을 이동하고, 비밀번호 보기·숨기기는 입력값이나 저장 방식을 바꾸지 않습니다.

아이디 중복확인은 `/username/check`에서 실제 계정을 조회하며 입력 변경 시 이전 확인을 지웁니다. 확인은 아이디를 예약하지 않으므로 최종 가입의 DB 유일성 검사도 유지하고 409 충돌 시 다시 확인하도록 안내합니다.

로그인 후 App은 user.name으로 이름을 표시하며 기존 이름 없는 계정은 ‘회원님’으로 표시합니다.

로그인한 회원의 ‘내 정보’에는 `MemberProfileForm`을 표시합니다. 한 화면에서 이름·만 나이·성별·지역을 수정하며 `/profile`에 저장합니다. 아이디는 읽기 전용입니다. 계정 정보와 추천용 설정은 자동으로 동기화하지 않습니다. 회원 저장 성공 시 헤더의 이름을 갱신하며 새로고침 시 `/me`에서 저장값을 복원합니다.

`authApi.js`는 dataMode와 관계없이 실제 인증 서버를 호출합니다. credentials=include, X-Auth-Request 헤더, 15초 제한과 외부 AbortSignal을 사용합니다. 화면을 떠나면 진행 요청을 취소합니다. 비밀번호·카카오 토큰·시크릿은 localStorage에 저장하지 않습니다. 세션 쿠키는 서버가 설정하며 App에서 /me로 로그인 상태를 복원합니다. 인증 성공을 가정하는 브라우저 전용 대체 모드는 없습니다.

[서버 계약·실행법](../../../../../backend/app/modules/auth/readme.md). `tests/e2e/auth.spec.js`는 실제 API 가입·로그인·회원 수정·세션·로그아웃, 아이디 중복과 최종 충돌, 단계별 검증·초점·화면 모드 전환을 데스크톱과 모바일 웹에서 확인합니다.
