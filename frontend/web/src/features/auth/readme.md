아이디 중복확인은 `/username/check`에서 실제 계정을 조회하며 입력 변경 시 이전 확인을 지웁니다. 확인은 아이디를 예약하지 않으므로 최종 가입의 DB 유일성 검사도 유지하고 409 충돌 시 다시 확인하도록 안내합니다.

로그인 후 App은 user.name으로 이름을 표시하며 기존 이름 없는 계정은 ‘회원님’으로 표시합니다.

로그인한 회원의 ‘내 정보’에는 `MemberProfileForm`을 표시합니다. 한 화면에서 표시 이름·만 나이·성별·주소를 선택적으로 수정하며 `/profile`에 저장합니다. 주소 검색 결과로 우편번호·기본 주소·시도를 반영하고 상세 주소를 직접 입력합니다. 이름·나이·주소는 비워 저장할 수 있고 성별은 ‘응답하지 않음’을 기본으로 합니다. 아이디와 이메일은 읽기 전용입니다. 일반 회원 수정에서는 계정 정보와 추천용 설정을 자동으로 동기화하지 않습니다. 회원 저장 성공 시 헤더의 이름을 갱신하며 새로고침 시 `/me`에서 저장값을 복원합니다.

`authApi.js`는 dataMode와 관계없이 실제 인증 서버를 호출합니다. credentials=include, X-Auth-Request 헤더, 15초 제한과 외부 AbortSignal을 사용합니다. 화면을 떠나면 진행 요청을 취소합니다. 비밀번호·카카오 토큰·시크릿은 localStorage에 저장하지 않습니다. 세션 쿠키는 서버가 설정하며 App에서 /me로 로그인 상태를 복원합니다. 인증 성공을 가정하는 브라우저 전용 대체 모드는 없습니다.

[서버 계약·실행법](../../../../../backend/app/modules/auth/readme.md). `tests/e2e/auth.spec.js`는 실제 API 가입·로그인·회원 수정·세션·로그아웃, 아이디 중복과 최종 충돌, 단계별 검증·초점·화면 모드 전환을 데스크톱과 모바일 웹에서 확인합니다.
