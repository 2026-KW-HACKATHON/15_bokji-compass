# 회원가입·로그인

`AuthPage({type, onLogin, easy})`는 아이디 로그인 및 회원가입 폼입니다. 가입 화면은 계정(아이디·비밀번호·확인), 기본 정보(이름·만 나이·성별·시도), 전화번호 인증으로 나뉩니다. 기본 화면은 세 영역을 이어서 보여주고, 쉬운 화면은 한 단계씩 보여줍니다. 다음 단계로 이동하기 전에 해당 입력을 확인하며, 이전 단계로 돌아가거나 화면 모드를 바꿔도 입력값은 유지됩니다. 단계 제목과 폼 상단 오류 안내로 초점을 이동하고 입력 오류에는 해당 입력란을 연결합니다. 비밀번호 보기·숨기기는 입력값이나 저장 방식을 바꾸지 않습니다.

로그인 후 App은 user.name으로 이름을 표시하며 기존 이름 없는 계정은 ‘회원님’으로 표시합니다. 전화번호 변경 시 인증 상태를 지우며 재전송·만료 시간을 표시합니다. 개발용 인증번호는 서버가 development_code를 반환할 때만 표시하며 실제 미발송 안내를 함께 보여줍니다. 계정 정보와 추천용 ‘내 정보’는 자동으로 동기화하지 않습니다.

`authApi.js`는 dataMode와 관계없이 실제 인증 서버를 호출합니다. credentials=include, X-Auth-Request 헤더, 15초 제한을 사용합니다. 비밀번호·인증 증명은 localStorage에 저장하지 않습니다. 세션 쿠키는 서버가 설정하며 App에서 /me로 로그인 상태를 복원합니다. 인증 성공을 가정하는 브라우저 전용 대체 모드는 없습니다.

[서버 계약·실행법](../../../../../backend/app/modules/auth/readme.md). 실제 문자 발송은 미연결입니다. `tests/e2e/auth.spec.js`는 실제 API 가입·로그인·세션·로그아웃 흐름, 전화번호 변경과 재발급 대기, 쉬운 화면의 단계별 검증·초점·모드 전환 입력 보존을 확인합니다.
