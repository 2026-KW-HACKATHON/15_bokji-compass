# 공고 캘린더

`#calendar`에서 공개 공고의 월별 신청 시작·마감 일정을 조회합니다. `CalendarPage`는
기존 공고 repository, 상세 보기, 브라우저 저장 기능을 함께 사용합니다.

- 한국 시간의 오늘을 기준으로 처음 표시하며 이전 달·다음 달·오늘 이동을 지원합니다.
- 검색어, 분야, 지역, 대상은 서버 필터입니다. 시작만/마감만은 조회된 월의 표시 필터입니다.
- 날짜를 선택하면 해당 일의 시작·마감 공고와 명확한 접수 기간에 포함되는 공고를 표시합니다.
- 상시 접수·날짜 확인 필요 공고는 별도 목록입니다. 없는 날짜를 추정하거나 예시 공고로 채우지 않습니다.
- 필터와 선택 날짜는 일반/쉬운 화면 전환 시 유지됩니다. 좁은 화면에서는 날짜별 목록을 달력 아래에 배치합니다.

`calendarModel.js`는 날짜 계산·월 격자·이벤트·접수 기간 판정을 담당합니다.
`createPolicyRepository().calendar(month, filters, {signal})`은 기존 `policiesPath` 뒤에
`/calendar`를 붙여 조회합니다. 응답과 날짜를 검증하며 요청 취소·늦은 응답 격리를 지원합니다.
서버 계약은 [API 관리대장](../../../../../api-management.md)의 공고 캘린더 항목을 따릅니다.

단위 검증: `tests/calendar.test.js`. PC/모바일 브라우저 검증:
`tests/e2e/calendar.spec.js`. 테스트 공고는 해당 테스트 안에서만 사용합니다.
