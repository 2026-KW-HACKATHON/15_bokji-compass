# 기능

2026-10-08 쉬운 화면 접근성: `app/easy-features.css`는 검색, 공고, 캘린더,
프로필, 계산기, 복지비서, 챗봇, 가입 동의 및 이용 안내의 쉬운 화면만 보완합니다.
본문은 18px 기준, 보조 안내는 0.94rem 이상이며 선택 상태는 색상과 굵은 테두리,
체크 표시 또는 밑줄을 함께 사용합니다. 필터/폼/대화 제어는 56px 이상의 높이와
줄바꿈을 지원하고 공고/프로필 설명은 줄 수 제한을 해제합니다. 캘린더는 날짜 입력과
접힌 월간 날짜 목록을 사용해 좁은 화면에서 작은 날짜 버튼을 피합니다.
일반 화면과 쉬운 화면의 데이터/API 계약은 같으며 이 스타일 파일은 기능별 CSS 뒤에
불러옵니다. Apple HIG 접근성의 명확한 정보 순서, 글자 확대, 터치 영역 원칙을 따릅니다.

담당: 프론트엔드. assistant는 개인비서 추천, policies는 공고 목록/검색/태그/상세, profile은 추천용 정보 입력/검증, auth는 인증 없는 폼입니다. notifications는 미구현 계획입니다.
모델·공급 어댑터는 React/DOM 없이 테스트하며 각 폴더 README에 입력/반환을 기록합니다.
