# 서비스 소개와 사용 안내

`GuidePage.jsx`는 `#guide` 경로에 표시하는 공개 안내 페이지입니다. 공고 탐색, 추천 정보 입력, 공고 저장과 일정 확인, 쉬운 화면, 신청 전 확인을 순서대로 설명합니다. 표시되는 예시 공고는 실제 모집 정보가 아니며 화면에 예시임을 명시합니다.

## 컴포넌트와 입력

- `GuidePage`: 기본 내보내기. `onExplore`, `onProfile`, `onCalendar`, `onCalculator`, `onEasyMode` 콜백을 받아 실제 기능으로 연결합니다. 로그인, 라우팅, 데이터 조회와 쉬운 화면 설정은 상위 앱이 관리합니다.
- `GuideArrow`: 아이콘을 포함한 텍스트 버튼. `children`, `onClick`, `light`를 받아 본문 CTA를 렌더링합니다.
- `ExampleLabel`: 데모의 예시 안내문. `children`을 생략하면 기본 설명을 표시합니다.

## 동작과 상태

관심 분야 버튼은 설명용 공고 예시를 전환합니다. 예시 공고의 책갈피는 로컬 컴포넌트 상태만 변경하며 실제 저장 목록에 기록하지 않습니다. 쉬운 화면 미리보기 스위치도 데모만 변경하고, ‘쉬운 화면으로 시작하기’ CTA가 실제 설정 콜백을 호출합니다.

목차 버튼은 해시 라우트를 변경하지 않고 해당 섹션으로 이동합니다. IntersectionObserver는 섹션 등장 효과와 현재 목차 표시를 담당하며 페이지가 사라지면 해제합니다. 동작 줄이기 환경설정에서는 떠다니는 이미지, 등장 효과, 부드러운 스크롤을 사용하지 않습니다. 브라우저가 IntersectionObserver를 지원하지 않으면 내용은 처음부터 표시됩니다.

## 스타일과 이미지

`guide.css`는 `.guide-page` 안으로 범위를 제한합니다. 상위 앱에서 안내 페이지 컨테이너에 전체 폭과 0 패딩을 제공하고, `--guide-sticky-top`으로 상단 탐색 영역의 높이를 전달합니다. 720px 이하에서는 세로 배치하고 목차를 한 줄로 축약합니다.

히어로 이미지는 `public/guide-compass.png`, 마지막 브랜드 표시는 `public/brand-logo.png`를 사용합니다. 이미지 안에 기능 UI를 넣지 않으며 데모와 모든 버튼은 실제 HTML로 구현합니다.
