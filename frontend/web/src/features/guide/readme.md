# 서비스 소개

`GuidePage.jsx`는 `#guide` 경로에 표시하는 공개 서비스 소개 페이지입니다. 공고 탐색, 추천 정보 입력, AI 생활 상황 대화와 챗봇, 공고 저장과 일정 확인, 쉬운 화면, 신청 전 확인을 순서대로 설명합니다. 표시되는 예시 공고와 대화는 실제 모집 정보나 상담 결과가 아니며 화면에 예시임을 명시합니다.

2026-10-07 다국어: `GuidePage`와 예시 안내는 `useI18n()`의 `t()`로 한국어·영어·중국어(간체)·베트남어·일본어를 표시합니다. 고정 설명·예시 데이터·버튼·이미지 대체 텍스트·접근성 레이블은 `frontend/packages/core/src/i18n/accountMessages.js`에 함께 관리합니다. 예시 선택·책갈피·쉬운 화면 미리보기 상태는 언어를 바꿔도 유지되며 예시임을 각 언어로 안내합니다. 공고 API나 실제 정책 본문은 이 페이지에서 번역하지 않습니다. 검증: 웹 빌드와 네 언어 사전 누락·치환값 확인.

`GuidePage.jsx`는 `#guide` 경로에 표시하는 공개 안내 페이지입니다. 공고 탐색, 추천 정보 입력, 공고 저장과 일정 확인, 쉬운 화면, 신청 전 확인을 순서대로 설명합니다. 표시되는 예시 공고는 실제 모집 정보가 아니며 화면에 예시임을 명시합니다.

## 컴포넌트와 입력

- `GuidePage`: 기본 내보내기. `onExplore`, `onProfile`, `onCalendar`, `onCalculator`, `onEasyMode`, `onAssistant`, `onChatbot` 콜백을 받아 실제 기능으로 연결합니다. `onAssistant()`는 AI 복지비서 화면을 열고, `onChatbot()`은 이 페이지에서 공통 챗봇 메뉴를 엽니다. 로그인, 라우팅, 데이터 조회와 쉬운 화면 설정은 상위 앱이 관리합니다. 각 콜백의 반환값은 사용하지 않습니다.
- `GuideArrow`: 아이콘을 포함한 텍스트 버튼. `children`, `onClick`, `light`를 받아 본문 CTA를 렌더링합니다.
- `ExampleLabel`: 데모의 예시 안내문. `children`을 생략하면 기본 설명을 표시합니다.
- `MotionReplay`: `sequence`와 `label`을 받아 해당 소개 연출을 다시 재생하는 버튼을 표시합니다. 동작 줄이기가 켜져 있으면 표시하지 않습니다.
- `useGuideSequence(duration)`: 연출 시간(ms)을 받아 `{ ref, phase, canAnimate, finish, replay }`를 반환합니다. `ref`를 데모 컨테이너에 연결하고 `phase`를 `data-guide-sequence`로 전달합니다. `finish()`는 대기와 재생을 종료해 모든 내용을 즉시 표시하고, `replay()`는 현재 선택값을 유지한 채 처음부터 재생합니다.

## 동작과 상태

관심 분야 버튼은 설명용 공고 예시를 전환합니다. 예시 공고의 책갈피는 로컬 컴포넌트 상태만 변경하며 실제 저장 목록에 기록하지 않습니다. 쉬운 화면 미리보기 스위치도 데모만 변경하고, ‘쉬운 화면으로 시작하기’ CTA가 실제 설정 콜백을 호출합니다.

목차 버튼은 해시 라우트를 변경하지 않고 해당 섹션으로 이동합니다. IntersectionObserver는 섹션 등장 효과와 현재 목차 표시를 담당하며 페이지가 사라지면 해제합니다. 동작 줄이기 환경설정에서는 떠다니는 이미지, 등장 효과, 부드러운 스크롤을 사용하지 않습니다. 브라우저가 IntersectionObserver를 지원하지 않으면 내용은 처음부터 표시됩니다.

공고 찾기, 맞춤 추천, AI 대화 데모는 25% 이상 화면에 들어오면 각각 2.8초/3.6초/4초의 순서 있는 연출을 한 번 재생합니다. 공고 찾기는 검색 문구 → 관심 분야 → 관련 공고 → 조건 안내, 맞춤 추천은 프로필 → 정보 칩 → 조건 비교 → 추천 공고 → 추천 이유, AI 대화는 상황 질문 → 추가 질문 → 응답 → 정리 내용 → 직접 기록한 신청 상태 순서입니다. 재생은 CSS의 opacity/transform으로 표현하며 내용을 자동으로 입력하거나 선택값을 변경하지 않습니다. 따라서 기존 aria-live 영역은 사용자가 분야를 바꿀 때만 새 내용을 알립니다. AI 예시는 정적 HTML이며 별도의 aria-live나 실제 상담 요청을 사용하지 않습니다.

AI 소개는 실제 `AssistantPage`, `GuidedConversation`, `FloatingAssistant`, `PolicyQuestion` 기능을 설명합니다. 생활 상황 대화와 공고 질문에는 로그인이 필요하고, 확인한 생활정보는 사용자 검토와 별도 동의 이후 저장됩니다. 관련 지원 후보는 자격 확정이 아니며 신청 진행 상태는 사용자가 직접 기록합니다. 챗봇은 동일한 생활 상담을 작은 창에서 시작해 AI 복지비서 화면으로 이어가는 진입점이며 별도의 추천 엔진으로 설명하지 않습니다. 답변의 원문 근거는 제공된 경우 확인할 수 있습니다.

데모를 클릭하거나 키보드로 진입하면 진행 중인 연출을 즉시 종료해 조작을 우선합니다. ‘다시 보기’는 수동 재생이며 선택한 분야를 초기화하지 않습니다. 분야 변경 시 결과 내용만 짧게 전환됩니다. 동작 줄이기 설정은 실행 중에 바뀌어도 즉시 반영하며 타이머, animation frame, 관찰자, 이벤트 구독은 페이지 종료 시 해제합니다.

검증 시 `[data-guide-sequence]`의 `idle → playing → complete` 전환과 세 다시 보기 버튼의 접근성 이름을 확인합니다. 접근성 이름은 ‘공고 찾기 소개 애니메이션 다시 보기’, ‘맞춤 추천 소개 애니메이션 다시 보기’, ‘AI 대화 소개 애니메이션 다시 보기’입니다. 일반 모션의 첫 진입·재진입, 재생 중 분야 선택, 키보드 진입, 동작 줄이기 환경과 실행 중 설정 변경을 확인하세요. ‘AI 대화’ 목차 이동과 ‘AI 복지비서 시작하기’/‘챗봇 열어보기’ CTA 연결도 확인합니다. 예시의 내용이나 실제 저장 데이터가 타이머로 변경되면 안 됩니다.

## 스타일과 이미지

`guide.css`는 `.guide-page` 안으로 범위를 제한합니다. 상위 앱에서 안내 페이지 컨테이너에 전체 폭과 0 패딩을 제공하고, `--guide-sticky-top`으로 상단 탐색 영역의 높이를 전달합니다. 720px 이하에서는 세로 배치하고 목차를 한 줄로 축약합니다.

히어로 이미지는 `public/guide-compass.png`, 마지막 브랜드 표시는 `public/brand-logo.png`를 사용합니다. 이미지 안에 기능 UI를 넣지 않으며 데모와 모든 버튼은 실제 HTML로 구현합니다.
