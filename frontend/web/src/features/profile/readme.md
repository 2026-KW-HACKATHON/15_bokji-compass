# 추천용 사용자 정보

2026-10-07 다국어: `ProfileForm`·`ProfilePage`는 공통 `useI18n()`을 사용하고 `accountMessages`의 UI 번역을 표시합니다. 선택지의 `value`와 모델의 지역·연령대·직업·가구·관심 분야는 기존 한국어 값을 유지하며 화면의 레이블만 `t(value)`로 번역합니다. 요약의 회원 이름·정확한 주소·우편번호는 그대로 표시하고 연령·가구원·차량·입력 개수는 치환값으로 번역합니다. 카테고리별 편집 초안, 탭 상태, 브라우저 저장 동의는 언어 전환 중 유지합니다. `profileSummary.js`의 순수 모델 반환과 API 전송 계약은 변경하지 않습니다. 검증: `node --test tests/profile-summary.test.js` 3개 통과, 웹 빌드 통과.

2026-10-07: 비회원의 `ProfileForm`은 시·도를 선택합니다. 회원 기본 정보는 `MemberProfileForm`에서 주소 검색·우편번호·기본 주소·상세 주소를 입력하고 서버 계정에 저장합니다. `profileRows('basic', user, profile)`은 회원의 저장 주소와 우편번호도 표시합니다. 기존 시·도만 저장한 회원은 해당 정보를 유지하면서 주소를 추가할 수 있습니다. 추천용 별도 지역 설정은 기존 시·도 선택을 유지합니다. [주소 입력](../../../../docs/member-address.md).

담당: 프론트엔드.

- `ProfilePage`: 기본 진입은 전체 요약이며 기본 정보 / 직업·가구 / 소득·재산 / 관심 분야 탭으로 한 카테고리씩 조회합니다. 저장된 값과 미입력 항목을 구분하고 추가·수정을 누르면 해당 폼을 펼칩니다. 회원 기본 정보는 기존 계정 API를 사용하며 나이 입력을 유지합니다. 생년월일 필드를 새로 저장하지 않습니다.
- 카테고리를 옮겨도 편집 중인 폼을 숨겨 유지합니다. 저장 시 해당 카테고리 필드만 최신 프로필에 병합하여 다른 탭의 저장 결과를 덮어쓰지 않습니다. 취소는 해당 편집을 버리고 조회 화면으로 돌아갑니다. 저장 후 내 정보 화면에 머물며 추천 요청과 브라우저 저장 동의는 기존 경계를 유지합니다. 계정 변경 시 탭·미저장 입력을 초기화합니다.
- `profileSummary.js`: 실제 회원·추천 값으로 요약과 입력 상태를 만듭니다. 만 나이 0 및 소득·재산 0은 입력된 값으로 취급하며 미확인 금액은 별도로 셉니다. 모델 검증은 `tests/profile-summary.test.js`에서 수행합니다.
- 소득·재산은 계산기와 공유하는 `useFinancePrefill`의 계정 조회 결과를 사용합니다. 회원으로 내 정보·빠른 계산기·상세 계산기를 방문하면 저장 API를 자동 조회하고 같은 계정의 결과는 메모리에서 공유합니다. 이번 방문의 계산 정보를 우선하고, 미저장 상세 초안이 있으면 ‘작성 중’으로 표시해 저장본을 현재 입력으로 오인하지 않게 합니다. 조회 실패를 미입력으로 오인하지 않도록 확인 중·확인 필요와 재시도를 제공합니다. 저장·명시적 불러오기 성공은 공유 캐시를 갱신하고 계정 금융정보 삭제는 진행 중 조회와 캐시를 무효화합니다. 상세 내역은 접힌 영역으로 제공하고 기존 상세 계산기 `#calculator-details`로 연결합니다. 계정 조회만으로 금융 정보를 추천에 포함하거나 자동 저장하지 않습니다.
- 상세 계산의 최초 초안은 회원의 확정 만 나이·구분 가능한 지역을 사용합니다. 연령대에서 정확한 나이를 만들거나 가족 동거 여부에서 가구원 수를 추정하지 않습니다. 빠른 계산기에서 선택한 실제 가구원 수는 상세 입력에서도 이어 쓰지만 가구 전체 월소득을 개인 소득으로 복사하지 않습니다. 이미 작성한 초안과 직접 수정한 값을 자동 조회 결과보다 우선합니다. 내 정보의 로그인 링크는 `#login?return=profile`이며 아이디 로그인 후 이 화면에 돌아옵니다. 카카오 신규 가입의 맞춤 정보 설정 흐름은 유지합니다.
- `profile.css`: 기존 색상 변수, Noto Sans KR, Lucide 아이콘, 카드·버튼·폼을 재사용합니다. 모바일에서 탭을 줄바꿈하고 카드·요약을 한 열로 배치하며 쉬운 화면의 글자·버튼 크기를 유지합니다. 탭은 방향키·Home·End로 이동할 수 있습니다.
- 검증: 빌드와 전체 Node 테스트 49개 통과. 별도 테스트 SQLite 서버와 인앱 브라우저에서 회원 이름·나이·지역 저장/새로고침, 추천 카테고리별 저장/브라우저 재방문, 탭 이동 중 입력 보존, 취소, 320px 쉬운 화면의 입력 보존·가로 넘침 없음, 계정의 소득·재산 조회 및 상세 계산기 전달을 직접 확인했습니다. 변경된 CLI E2E는 실행하지 않았습니다.

- defaultProfile: {region,ageBand,occupation,household,interests}. 미선택은 선택하지 않음.
- isProfile(value) → boolean. 선택값/배열 손상 검증.
- recommendationProfile(value) → 선택 필드만 복사한 전송 모델. `null`/`undefined`는 일반 공고 요청용 `{}`를 반환합니다. 미선택 null·중복 관심사 제거. 그 외 잘못된 값은 throw. 반환된 객체가 존재한다는 사실만으로 맞춤 추천에 충분한 정보라고 판단하지 않습니다.
- ProfileForm({profile,onSave,easy,remembered,mode,section,onCancel}) → React 폼. onSave(profile,remember) 호출. `section`이 있으면 해당 카테고리만 편집하고 저장·취소를 제공합니다. 모드 전환 시 입력과 기억하기 선택을 보존합니다.
  폼 자체는 저장/네트워크를 수행하지 않습니다. app이 메모리 보관 또는 기억하기 선택 시 localStorage 저장 후 추천 요청합니다. 자격 판정용 사실 확정이 아닙니다.
  검증 범위: Node 모델 테스트, 브라우저 한 폼 제출·추천 3개 표시·모드 양방향 입력 보존. 현재 확인 결과와 미실행 E2E는 [쉬운 화면 문서](../../../../docs/senior-mode.md)에서 구분합니다.
