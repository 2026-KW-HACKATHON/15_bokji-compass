# 앱 조립

담당: 프론트엔드. `App()`은 props 없이 React 화면 트리를 반환합니다. 홈·탐색·저장·프로필 상태, 해시 URL, 필터와 모달을 조립합니다. `styles.css`는 색상 토큰·레이아웃·모바일 safe-area·반응형 규칙을 정의합니다.

업무 데이터는 `listPolicies()`에서, 로컬 설정은 shared 저장소 어댑터에서 받습니다. 외부 HTTP 호출은 서비스 안내의 연결 확인 버튼에서만 발생합니다. 예시 정책/저장/프로필/팝업/뒤로 가기는 `tests/e2e/app.spec.js`로 검증합니다.
