# 앱 조립

담당: 프론트엔드. App() → React 화면. hash 메뉴·tag, 프로필·추천 요청 상태·쉬운 화면·저장/상세를 조립합니다.
services.js는 공개 설정을 바탕으로 공고/추천 repository를 생성합니다. API 모드에서만 서버 호출하며 이전 요청은 취소합니다.
styles.css는 녹색 테마·모바일 safe-area·쉬운 화면·모션 감소 규칙을 제공합니다.
검증: Node 계약 테스트, 브라우저 단계 입력·태그·뒤로가기·저장·인증폼·반응형 흐름.

브랜드는 파랑 #0068B7·초록 #087B52로 확정했습니다. public/brand-logo.png를 데스크톱/모바일 브랜드, 푸터, 탭 아이콘에 사용하며 개인비서 메인 로고에도 동일 이미지를 사용합니다. 최신 개인비서·쉬운 화면·API 기능은 유지합니다.
