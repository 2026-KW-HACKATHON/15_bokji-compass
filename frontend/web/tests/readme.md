## 브라우저 시나리오

`npm run test:e2e`는 Microsoft Edge/Chromium desktop/mobile 프로젝트에 다음 파일을 적용합니다.

- `e2e/app.spec.js`: 검색/태그/상세/저장, 쉬운 화면 프로필 한 폼·공고 3개 목록·설정 유지, 320px, 공고 API 실패/재시도. 모드 전환 시 작성 중 기본 프로필·저장 선택·검색 draft/적용 조건/태그/정렬 유지. 저장 목록 두 번째 페이지에서 4개→3개로 줄어도 남은 공고 모두에 접근할 수 있는 경계 시나리오 포함.
  두 번째 공고 페이지에서 검색어·지역·대상을 적용하면 cursor가 초기화되고,
  결과 건수가 갱신되며 조건 지우기로 전체 목록이 복원되는 흐름을 확인합니다.
  일반/쉬운 화면의 요약·신청 기간·지급 시기를 서로 다른 항목으로 표시하는 흐름도 검증합니다.
