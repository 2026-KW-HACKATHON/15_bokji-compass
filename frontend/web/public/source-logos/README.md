# 공고 출처 로고

공고 수집기가 지원하는 사이트의 출처 표시용 공식 로고입니다. 스폰서·제휴 관계를 의미하지 않습니다. 로고의 권리는 각 기관에 있습니다. 원본의 색과 비율을 유지하며 웹 내부 정적 자산으로 제공합니다.
