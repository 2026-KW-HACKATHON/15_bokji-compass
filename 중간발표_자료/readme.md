## 기존 자료

2026년 9월 23일 기준 복지나침반 계획과 개발 현황을 정리한 자료입니다.

- [사업계획서 및 중간 개발 보고](복지나침반_사업계획서.md): 문제 정의, 사용자, 구현 현황, 실증 결과, 개발 계획, 공식 출처와 차별화 검토.
- [중간발표 PPT](복지나침반_중간발표.pptx): 본 발표 10장과 팀 미합의 참고안 4장. 발표자 노트에 설명과 출처를 포함합니다.

본 발표는 약 7분, 참고안 포함 약 11분을 가정합니다. 11~14장과 사업계획서 11절은 팀 논의용이며 확정 개발 범위가 아닙니다. 현재 웹의 예시 추천과 실제 서버 기능을 구분해 발표하세요.

공식 서비스 비교는 복지멤버십, 복지로 전체 기능, 정부24 혜택알리미의 범위를 구분합니다. 사례로 인용한 모집 공고는 현재 접수 가능한 목록이 아니며, 최신 조건은 연결된 공식 원문에서 확인합니다.
