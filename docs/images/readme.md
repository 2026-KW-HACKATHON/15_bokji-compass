| 파일 | 내용 |
|---|---|

캡처에는 합성 예시 공고 사용. 실제 개인 정보·로그인 계정·금융 입력은 포함하지 않음. 로고는 `frontend/web/public/brand-logo.png`를 그대로 사용.

README 구성 참고: [Supabase](https://github.com/supabase/supabase), [Dify](https://github.com/langgenius/dify), [Cal.diy](https://github.com/calcom/cal.diy). 제품 소개·화면·기능·문서 연결 방식만 참고했으며, 문구와 이미지는 복지나침반 자료로 작성.

## 유사 서비스 분석 근거

`paradise-hero-2026-10-02/`는 2026-10-02 공개 사이트 [K-복지 리서치랩](https://paradise-hero.com/)에서 직접 캡처한 화면이다. 경쟁 서비스 분석·내부 개선 검토의 근거이며 복지나침반의 제품 화면이나 홍보 이미지가 아니다. 실제 사용자 개인정보는 입력하지 않았고 가상의 진단 조건을 사용했다. 이미지를 편집하지 않고 원본 캡처를 보관했다.

| 파일 | 확인한 화면 |

관찰 범위·공식 자료 대조·실행 체크리스트는 [유사 복지 서비스 개선 작업](../../frontend/docs/competitor-lessons-todo.md)에 기록했다. 화면의 정책 정보는 공식 안내와 다를 수 있어 신청 판단의 출처로 사용하지 않는다.
