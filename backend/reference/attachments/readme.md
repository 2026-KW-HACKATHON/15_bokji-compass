# 공식 공고 첨부 참고 목록

`kwangwoon.json`은 기존 광운대 참고 공고 190개의 DUID별 실제 공식 첨부 파일명·URL 목록입니다. 2026-10-08 공식 공고 HTML에서 확인한 238개 파일을 기록합니다. 원문 파일의 바이너리나 장학생 명단 내용은 포함하지 않습니다.

기존 공고를 새 서버에 설치했을 때에도 실제 파일 링크가 제공되도록 하는 기본 목록입니다. 새 수집 결과의 `attachment_files`와 서버에서 갱신한 manifest가 이 참고 목록보다 우선합니다. 실제 파일은 [첨부 모듈](../../app/modules/attachments/readme.md)에서 클릭 시 또는 명시적 보충 명령으로 저장합니다. 정규화 원문·자격 근거로 사용하지 않습니다.
