구현
- PolicyRepository마다 PublicCatalogCache를 생성한다. 새 의존성·DB 스키마 변경은 없다.
- 공개 목록·검색·상세·옵션·캘린더 응답을 30초 재사용한다.
- 결과는 최대 256개/JSON 합계 16MiB LRU로 제한한다. 반환값은 독립 JSON이다.
- 같은 버전·요청의 동시 캐시 미스는 한 번만 계산한다.
- 공개 원문·기관 어휘·공고 묶음 스냅샷 하나를 공유한다.
- 후속 검색/필터는 같은 SQL 조건·정렬로 개정 ID와 필요한 자격 열만 읽는다.
- 목록은 DB 연결을 반납한 뒤 필터·검색 순위·카드를 만든다.
- 매 요청에서 DB의 공개 개정 ID·원문 해시·분석 fingerprint·listing SHA-256을 확인한다.
- 철회·새 공개·새 수정 개정·조회수 변경은 캐시를 무효화한다. DB 확인 실패 시 오래된 결과를 제공하지 않는다.
- 저장 계약대로 원문/draft는 불변 개정이다. 직접 SQL로 기존 JSON만 덮어쓰는 방법은 지원하지 않는다.
- 한국 시간 날짜도 결과 키에 포함한다. member/eligible_only 결과는 공용 응답 캐시에 저장하지 않는다.
- 프로세스 수를 유지하여 메모리 대화 상태의 프로세스 간 분산 문제를 만들지 않았다.
