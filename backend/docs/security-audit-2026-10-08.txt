복지나침반 운영 보안 점검 — 2026-10-08 (한국 기준)
대상: https://bokji.commitnaru.com/
범위: 소유자 허가에 따른 비파괴 운영 점검 + 로컬 코드 읽기

결과
인증 우회·관리자 권한 탈취·실제 개인정보 유출은 확인하지 못했습니다.
확인된 운영 취약점 1건과 보안 설정 보완 항목 1건이 있습니다.

BC-01 / 중간 / 평문 HTTP에서 앱과 인증 API 제공
- http://bokji.commitnaru.com/ → 200, Location 헤더 없음.
- 최종 비교에서 HTTP/HTTPS HTML의 SHA-256이 같습니다.
- http://bokji.commitnaru.com/app-config.js → 200.
- HTTP 로그인 API에 형식이 잘못된 합성 입력을 보내면 422로 검증합니다.
  실제 계정·비밀번호는 사용하지 않았으며 로그인 함수가 실행되는 입력을 보내지 않았습니다.
- HTTPS의 HSTS max-age는 86400(1일)입니다. HTTP의 HSTS는 브라우저가 무시합니다.
영향: HSTS/HTTPS 자동 승격 보호가 없는 HTTP 접속에서는 네트워크 공격자가
페이지를 변조하거나 입력을 가로챌 가능성이 있습니다. 이는 확인된 평문 제공으로부터
추론한 위험이며, 이번 점검에서 실제 도청이나 계정 탈취를 수행한 것은 아닙니다.
수정: 공개 Cloudflare 경계에서 해당 호스트의 HTTPS 전환을 강제하고, 인증 API의
평문 요청을 거부하세요. 정적 내부 Caddy HTTP 리스너 전체에 단순 리다이렉트를
추가하면 TLS 종료 터널 환경에서 루프가 생길 수 있으므로 외부 경계에서 적용하세요.
검증: HTTP 루트는 HTTPS Location이 있는 영구 리다이렉트, HTTP 인증 API는
앱 처리 전에 차단, HTTPS 사이트·로그인 흐름은 정상이어야 합니다.

BC-02 / 낮음 / 운영 보안 헤더와 로컬 배포 설정의 차이
- 운영 HTML: style-src 'self' 'unsafe-inline'; style-src-elem 없음.
- 로컬 배포 파일: style-src-elem 'self'; style-src-attr 'unsafe-inline'.
- 운영 HTML에는 COOP/CORP가 없지만 민감한 API에는 적용되어 있습니다.
영향: 독립적인 HTML 삽입 취약점이 있으면 인라인 style 요소를 통한 화면 변조가
허용됩니다. HTML 삽입·CSS 정보 탈취·XSS 성공은 확인하지 않았습니다.
수정: 현재 검토된 CSP/헤더 설정을 실제 배포 경계에 반영하고 주소 검색·React
스타일과 화면 표시를 검증하세요. 보완 항목이며 독립적인 침투 성공으로 보지 않습니다.

차단 확인
- 회원/금융/모니터링/관리자 API: 비로그인·위조 쿠키·위조 Bearer는 401.
- 관리자 역할 헤더 위조: 401. 서버 관리자 설정·API 문서: 공개 경계에서 404.
- 외부 Origin·null Origin·교차 사이트 탐색: 403, 비허용 CORS 사전 요청: 400.
- 인증 전용 헤더 누락: 403; 중복 JSON: 422; text/plain: 415.
- 잘못된 로그인 입력: 422, 비밀번호 마커를 응답에 반사하지 않음.
- 점검한 .env/.git/메인 JS 소스맵 경로: 404. 다른 경로까지 보장하지 않습니다.
- 작은 literal 검색의 SQL 형태 입력: 결과 0개, SQL 오류 없음. 전체 SQL 주입 검증은 아닙니다.
- 브라우저 SVG/onload 검색 입력: 입력값으로 유지, 생성된 공격 요소 0개, 제목 변화 없음.

점검 한계
- 유효한 회원/관리자 테스트 자격증명이 없어 계정 간 IDOR·로그인 후 권한 상승·
  실제 세션 쿠키 발급 속성은 운영에서 검증하지 않았습니다.
- 무차별 대입·부하 테스트·저장형 페이로드·메일 발송·회원 생성/수정/삭제는 하지 않았습니다.
- 로컬 터미널 실행 오류로 로컬 테스트 실행은 하지 못했습니다. 소스는 읽기만 했습니다.
- 점검 중 메인 번들 이름이 바뀌었습니다. 결과는 응답을 받은 시점의 배포 상태입니다.
- 운영 설정과 코드에 변경을 적용하지 않았습니다. 보안 보장은 아닙니다.
