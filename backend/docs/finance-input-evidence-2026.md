- 검토일: **2026-09-25**
- 범위: 공식 지침, 국세청 법령, LH 실제 모집공고 2건의 확인 결과.
- PDF 쪽수는 **문서에 인쇄된 쪽수**다. 아래 LH 공고 2건은 PDF 페이지 순서와 인쇄 쪽수가 일치한다.
- 이 문서는 근거 조사 기록이다. 입력 필드가 추가되었다고 해당 예외의 자동 계산까지 구현된 것은 아니다. 구현 범위는 `financial-rules.md`와 실제 계약·규칙 코드를 함께 확인한다.

## 1. 소득 입력의 세전·세후와 조회 기간

### 근로소득

LH의 2026년 3월 국민임대 사전 안내 1쪽에는 **“월평균소득액은 세전금액”**이라고 명시되어 있다. 통장에 입금된 실수령액을 그대로 입력하도록 안내해서는 안 된다. [S3]

기초생활 지침은 근로의 대가인 소득을 정의하면서 비과세 근로소득을 원칙적으로 제외하고, 연장·야간·휴일근로 급여와 일부 국외근로 급여 등을 다시 포함한다. 따라서 급여명세서의 모든 세전 지급 항목을 예외 없이 합산한 값이 최종 심사 소득과 항상 같지는 않다. 공적자료로 조회한 금액과 인정되는 증빙이 우선한다. [S1, 108~109쪽]

화면에는 `근로소득(세전 기준)`으로 표시하되, 세금·보험료를 빼기 전 금액을 참고하며 공적자료·비과세 항목에 따라 심사 금액이 달라질 수 있다고 설명한다. 사업별 근로소득공제를 사용자가 미리 차감한 값을 입력하지 않도록 한다.

**확인 한계:** S1 전체 및 S2 관련 소득 조항에서 세전·세후를 직접 규정한 동일 표현은 발견하지 못했다. 위 UI 표현은 LH의 직접 근거와 복지 지침의 소득 정의·자료 조회 방식을 함께 고려한 입력 안내이며, S1에 해당 문구가 있다고 인용하지 않는다.

### 사업소득

| 확인 사항 | 근거와 입력에 미치는 영향 |
| --- | --- |
| 매출과 소득의 구분 | 국세청 사업소득금액은 총수입금액에서 필요경비를 차감한 금액. 매출액 전체나 통장 잔액과 다르다. [S4, 소득세법 제19조 제2항] |
| 소득세 처리 | 소득세·개인지방소득세는 필요경비에 넣지 않는다. 따라서 안내는 `필요경비 차감 후, 소득세·개인지방소득세 차감 전`이 적절하다. [S4, 제33조 제1항 제1호] |
| 다른 세금의 처리 | 부가가치세 매출세액은 총수입금액에 산입하지 않는 등 세목별 처리가 다르므로 `모든 세금 차감 전`이라는 안내는 피한다. [S4, 제26조 제9항] |
| 복지 지침의 기본 자료 | 국세청 경비 제외 사업소득을 월할한다. 사회보험 직장가입 사업자는 사회보험 소득자료가 우선될 수 있고, 인적용역 제공자는 경비율·실제소득 확인 등 별도 절차가 있다. [S1, 92·113~114쪽] |

입력 계약은 매출·필요경비·소득세를 혼합한 하나의 모호한 금액 대신 위 정의를 설명해야 한다. 개별 거래의 필요경비 인정이나 업종별 경비율을 LLM이 추정해 자동 공제하지 않는다.

### 조회 기간과 소득자료

아래는 기초생활·차상위 지침의 기본 조사 방식이다. 국민임대의 개별 공고에 무조건 동일하게 적용한다는 뜻은 아니다. [S1, 92·100·109쪽; S2, 33쪽]

| 소득·상황 | 확인한 기본 기준 |
| --- | --- |
| 상시근로·사업·이자·임대 | 공적자료에서 조회한 연간소득의 평균 |
| 일용근로 신청조사 | 최근 3개월 평균 |
| 일용근로 확인조사 | 최근 6개월 평균 |
| 기타 사업소득 변동을 소명한 경우 | 최근 3개월 평균 적용 가능. 이후 매월 신고 등의 조건 확인 필요 |
| 자활·공공일자리·연금·공적이전 | 전월소득 |
| 신규취업·이직·실직·퇴직·휴직·복직·폐업 | 변경 발생월부터 변경 상태 반영 |

상시근로 공적자료는 건강보험 보수월액 → 근로복지공단 월평균보수 → 국민연금 기준소득월액 → 장애인고용공단 → 국세청 순으로 확인한다. 원천기관의 자료 갱신 시기와 적용 기간이 다르므로 `현재 월급`, `연평균`, `최근 3개월 평균`을 동의어로 취급하지 않는다. [S1, 92·109쪽; S2, 33쪽]

### 연금·기타소득

개인연금은 금융정보 조회결과를 적용하고 연 1~2회 받는 상품은 월할한다. 일시금은 금융재산으로, 국민연금 등 공적연금은 공적이전소득으로 분류한다. 주택연금·농지연금도 별도 규정이 있다. [S1, 117쪽]

모든 연금·기타소득의 세전·세후 처리를 하나로 단정할 직접 규정은 이번 조사에서 확인하지 못했다. 따라서 `기타소득` 전체에 근로소득과 같은 안내·공제·조회 기간을 자동 적용하지 않는다. 소득 종류별 지급내역과 공적 조회값의 정의를 확인해야 한다.

## 2. 실제 LH 공고의 차량 조건 비교

검토한 공고는 인천검단 AA19 국민임대 최초 모집(2026-08-20, 정정공고 게시물)과 완주삼봉 A-1·A-3 행복주택 자격완화 예비입주자 모집(2026-08-19)이다. 실제 원문과 PDF 수집 주소는 S5·S6에 함께 기록했다.

| 항목 | 확인한 공고 내용 | 인천검단 S5 | 완주삼봉 S6 |
| --- | --- | --- | --- |
| 총자산에 넣는 차량 | 심사 대상 세대가 보유한 자동차의 가액을 합산. 비영업용 승용차만 합산한다는 규정이 아님 | 7~8·27쪽 | 29쪽 |
| 별도 자동차 한도 | 비영업용 승용자동차가 대상. 여러 대이면 해당 자동차 중 가장 높은 가액을 비교 | 8·28쪽 | 29쪽 |
| 장애인사용 자동차 | 법정 요건에 해당하는 장애인사용 자동차는 총자산 차량 합계와 별도 자동차 한도에서 제외 | 8·27~28쪽 | 29쪽 |
| 국가유공자 보철용 | 상이등급 1~7급에 해당하는 국가유공자의 보철용 차량은 두 기준에서 제외 | 8·27~28쪽 | 29쪽 |
| 저공해차 보조금 | 해당 법령에 따른 국가·지자체 보조를 받아 구입한 저공해차는 차량가액에서 그 보조금을 차감. 두 기준에 규정됨 | 8·27~28쪽 | 29쪽 |
| 가액 자료 | 사회보장정보시스템으로 확인하는 차량기준가액. 자료 출처는 보험개발원 차량기준가액·지방세정 시가표준액·국토부 차적정보 | 29~30쪽 | 31쪽 |
| 리스·회사 차량 | 임차인 전용 리스차량·근무회사 차량을 단지 주차 허용 범위에 언급. 단지 차량등록 가액 제한도 별도 명시 | 31쪽 | 35쪽 |
| 대학생 계층 | 자동차가액 산출대상 자동차의 미소유 요건과 차량등록 제한 유지 | 해당 계층 없음 | 10~11·35쪽 |

`사업에 사용하는 차량`과 자동차 등록상 `영업용`을 같은 것으로 가정하지 않는다. 예를 들어 개인 승용차를 출퇴근이나 업무에 쓴다는 답변만으로 별도 차량 한도에서 제외할 수 없다. 반대로 등록상 영업용이라고 확인되더라도 총자산에서 차량을 통째로 빼는 것은 위 공고의 총자산 규정과 맞지 않는다.

장애·국가유공자 여부만으로 차량 제외를 확정하지 않는다. 법정 차량 요건과 해당 차량의 증빙을 확인해야 한다. 전기차라는 이유만으로 임의의 보조금 액수를 차감해서도 안 된다. 주차 규칙에 나오는 리스·회사 차량은 입주자 자산 심사에서의 소유·가액 산정과 별도로 관리해야 한다.

### 공동명의: 확인한 근거와 남은 부분

두 공고 본문에서 자동차 공동명의의 구체적인 지분 산정 조항은 찾지 못했다. 다만 추가로 확인한 **2026-06-22 시행 국토교통부고시 제2026-293호**의 제3조 제2항은 총자산 산출 시 자동차 등 공유재산을 해당 지분가액으로 보고, 같은 세대원 사이의 지분은 합산하도록 규정한다. [S7]

따라서 지분 정보가 필요하다면 개인 한 명의 지분과 심사 대상 세대 전체의 지분을 구분해야 한다. **별도 자동차 최고가 한도에도 같은 지분율을 그대로 곱한다는 직접 근거는 이번 조사에서 확인하지 못했다.** 총자산의 지분 조항을 별도 한도나 다른 복지사업에 자동 확장하지 않는다. 해당 분기는 공고별 확인 전까지 추가 검토 대상으로 남긴다.

### 공고 자체가 바꾸는 추가 변수

- 인천검단은 출생자녀 수에 따른 소득·총자산·자동차 한도 가산을 별도로 둔다. 단순 미성년 자녀 수만으로 적용하지 말고 출생 시기·태아·입양 등 공고 조건을 확인해야 한다. [S5, 6쪽]
- 완주삼봉은 **금회 소득·총자산 요건을 배제하는 자격완화 공고**다. 대학생은 자동차 미소유 요건을 유지하고, 청년·신혼부부 등의 자동차 한도는 유지한다. 일반 행복주택의 소득·총자산 표로 이 공고를 자동 탈락 처리하면 안 된다. [S6, 10~14쪽]
- 행복주택은 대학생·청년·신혼부부 등에 따라 본인·부모·세대 등 심사 범위가 다르고 최초계약과 갱신 조건도 다르다. 공고 유형, 공급 계층, 세대 범위, 자격완화, 계약 단계가 규칙 선택의 입력이어야 한다. [S6, 10~14·33~34쪽]

## 3. 입력 계약과 자동 산정의 구분

아래는 확인된 차이를 표현하기 위해 필요한 **데이터 분류**다. 기존 필드에 자동 대응한다고 가정하지 않으며, 정확한 필드명·버전은 계약 코드에서 관리한다.

| 수집·구분할 정보 | 자동 처리를 위해 추가로 필요한 확인 |
| --- | --- |
| 근로·사업·개인연금·공적이전 등 소득 종류 | 세전 여부, 필요경비 반영 여부, 조회 기관, 기준 기간, 예외 항목 |
| 차량 법정 종류와 등록 용도 | 승용·승합·화물 등의 분류 및 영업용 여부. 사용자 설명상의 사업용과 분리 |
| 본인·세대 소유, 공동명의, 리스·렌트·회사 차량 | 심사 세대와 소유 범위. 자산 심사와 단지 주차 규칙 분리 |
| 차량 전체 가액과 세대 지분 | 총자산용 지분 합산과 별도 차량 한도의 차이 확인 |
| 장애인사용·보철용 등 예외 사유 | 법정 요건 및 차량별 증빙. 미확인 선택값만으로 자동 제외 금지 |
| 저공해차 정부·지자체 보조금 | 실제 지급액, 해당 법령·공고의 차감 허용 여부, 중복 차감 방지 |
| 차량가액과 조회 시점·출처 | 공적 기준가액인지, 보조금·지분 조정 전인지 구분 |
| 공고별 자격완화·출생자녀 가산·계약 단계 | 실제 공고 원문과 적용 범위 검토 |

공식 규칙이 있더라도 필요한 입력·증빙이나 계산 분기가 미구현이면 `needs_review`로 남긴다. 미입력값을 0으로 보거나 기본값을 자동 제외 근거로 사용하지 않는다. LLM은 불명확한 등록 용도·소유·보조금·장애 예외를 추정해 판정하지 않는다.

차량가액 조회 안내는 [국세청 홈택스](https://www.hometax.go.kr)를 사용할 수 있다. 다만 공고 자체가 개인별 차량가액과 조회금액의 차이 가능성을 명시하므로 조회액을 최종 심사가액으로 보장하지 않는다. 안정적인 공개 직접 조회 화면 URL은 이번 조사에서 확인하지 못했다. [S5, 31쪽; S6, 35쪽]
