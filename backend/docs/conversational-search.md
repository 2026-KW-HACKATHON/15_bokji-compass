# 상황 설명형 자연어 검색 (2026-10-08)

`나는 휴학한 학생이고 지원금과 관련된 정보가 필요해`가 0건이던 이유는
`휴학한`, `이고`, `정보가`가 각각 필수 원문 검색어로 남았기 때문이다.
`search.interpretation.interpret_query(query, institutions=()) -> SearchPlan`은
인식한 대상·지원 목적의 조사와 연결 어미를 제거하고, 거주·재학·휴학·취업 준비 문구를
상황 정보로 읽는다. 남은 지역명과 사업명은 기존 필수 검색 조건으로 유지한다.

`SearchPlan.contexts`의 `student_leave`는 휴학 상황이고, `background_concepts`는
필수 지원 목적과 구분한 배경 분야다. ‘취업 준비 중인 청년인데 월세 지원’은
월세를 찾되 취업 분야는 순위 참고로 쓴다. 단독 취업 요청은 기존 필수 검색으로 유지한다.
휴학 부정 표현은 휴학 상황으로 넣지 않는다. 검색 입력 상한은 기존 200자다.

`retrieval.rank_records(records, plan, sort='relevance')`는 공개 원문에 휴학생의
신청 안내가 있으면 순위를 보완하고, 휴학생 제외/불가 또는 재학생만을 대상으로 하는
공고는 순위를 낮춘다. `제외대상` 아래의 번호 목록도 확인하므로
`휴학생(학사징계자 포함)`을 허용 안내로 바꾸지 않는다. 근거는 실제 원문 인용이며,
확인되지 않은 신청 자격을 생성하거나 결과를 자동으로 신청 가능 처리하지 않는다.
일반 지원도 유지하고 검색 해석의 warnings로 휴학·재학 요건 확인을 안내한다.

목록과 캘린더 및 AI 비서의 공개 공고 검색은 같은 계획과 순위를 사용한다.
DB 원문 수정·회원 상태 저장·외부 모델 호출 없이 동작한다. 직접 선택한 단어 검색
(`search_mode=literal`, 기관/본문 범위)는 기존 계약을 유지한다.

검증: `tests/test_conversational_search.py`는 상황형 문장, 취업 준비/월세 분리,
지역·사업명 유지, 휴학 부정, 제외 문맥, 실제 원문 근거와 결과 순서를 확인한다.
실제 공개 DB에서도 학생 금전 지원·생활비·월계동·청년 월세 문장을 읽기 전용으로 조회한다.
이는 검색 관련성 확인이며 실제 개인 자격이나 현재 접수 여부를 확정하지 않는다.
