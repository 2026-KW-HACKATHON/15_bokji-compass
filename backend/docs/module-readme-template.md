# 모듈 README 작성 양식

담당: 변경 영역 담당자. 모듈의 실제 코드와 일치하는 내용으로 작성하며, 미구현 폴더는 빈 문서 대신 미구현 상태와 현재 구현 위치를 안내합니다. 이 문서 자체에는 실행 함수가 없습니다.

```markdown
# 모듈 이름

## 역할·현재 상태
담당 영역/담당자, 구현·계획 구분, 이 폴더의 책임과 제외 범위.

## 공개 진입점
함수/컴포넌트명과 파일, 입력 타입·필수/기본값, 반환 타입·의미,
동기/비동기 여부, 발생 가능한 오류, 호출 예시.
구현이 없으면 호출 함수·반환값이 없다고 명시.

## 외부 호출·저장
HTTP/DB/CLI/파일 접근 유무, 설정 변수명과 기본값, 부작용.
실제 키·암호·원본 개인정보는 기록하지 않음.

## 검증
명령과 실행 디렉터리, 검증 범위, 대역/실제 서비스 구분,
성공·실패 결과, 별도 위치의 테스트 링크.

## 미구현·관련 문서
현재 한계, 후속 책임, 계약·루트 API 관리대장·작업 기록 링크.
```

공개 HTTP 경로가 추가되면 [루트 API 관리대장](../../api-management.md), [API 문서](api/readme.md), 실제 생성 OpenAPI와 호출자 문서를 같은 변경에서 갱신합니다. 내부 `public.py` 함수가 있다는 이유로 HTTP API가 구현되었다고 기록하지 않습니다.
