# 노원구·월계1동 생활 복지 데이터 수집 근거

공식 안내 조회일: 2026-10-08 (Asia/Seoul). 데이터 파일: `backend/reference/local_services/services/nowon.json`.

총 8건이다. 월계1동 상담 창구 1건과 월계1동 소재 시설 3건을 우선 탐색 대상으로 수집했다. `coverage`는 탐색 범위이며, 사업 자격은 `audience`에 따로 기록한다. `focusAreas`는 공식적으로 확인한 시설 소재 행정동에 따른 정렬용 정보이고 해당 동 거주자에게만 이용 자격이 있다는 뜻이 아니다. 법정동인 월계동을 월계1동으로 바꾸지 않았다.

`checkedAt`은 웹 자료 조회일이다. 실시간 운영·잔여 정원·예약 성공을 뜻하지 않는다. 본문에 게시일을 확인하지 못한 안내의 `sourcePublishedAt`은 `null`이다. PDF URL의 날짜처럼 보이는 문자열을 발행일로 사용하지 않는다.
