# 실제 데이터 스키마 적용 예시

2026-09-21 수집한 Gov24 5개·복지로 1개 정책과 기존 Codex CLI 분석 결과 사용. 실제 DB 변경 없이 제안 스키마로 정렬한 검토용 데이터 생성.

## 결과 파일

- [전체 정렬표](../data/schema-samples/20260921/readme.md): 정책별 조건·적용 그룹·미해결 항목.
- [JSON](../data/schema-samples/20260921/normalized-sample.json): 정책, 조건, 그룹, 원문·근거, 상태.
- [CSV](../data/schema-samples/20260921/conditions.csv): 조건 행 조회용 UTF-8 BOM 파일. 빈 셀은 JSON의 null에 해당.

결과와 원천 스냅샷은 Git 제외. 다른 PC에서는 원천 스냅샷을 별도 전달받아 아래 명령으로 재현. API 키·DB 설정 불필요.

## 상태와 값

| 상태 | 의미 | 예시 |
|---:|---|---|
| 0 | 원문에 명시된 제한 없음 | 특정 중증장애 부양가족의 나이 제한 면제. 값 null, 적용 범위 보존 |
| 1 | 값 있음 | 무소득: 소득 값 0. 숫자 0도 정상적인 실제 값 |
| 8 | 미처리 | 이번 검토 완료 표본에서는 사용 없음 |
| 9 | 분석 후 정보 없음 | 지역 미기재, 외부 심사규정 상세 미확인. 사유 별도 보존 |

정책 ID → 항목 → 주체 → 그룹 → 조건 ID 순 정렬. 조건 ID와 그룹 ID는 해당 표본 내부 식별자.

## 지역 코드와 미완료 항목

- `state_code`와 `value_code`/`region_id` 분리. 공식 코드 안의 0·9는 원래 코드의 일부로 유지.
- 지역 코드 미수집으로 `regions`, `condition_regions`는 빈 배열. 기관 소재지·신청기관 주소·전국 단위 기관을 거주 조건으로 대체하지 않음.
- 60개 기존 후보 보존, 지역 정보 없음 6개와 원문에 명시된 조건부 나이 면제 1개 추가. 나이 면제는 기존 복합 후보의 일부를 분리한 행으로, 독립된 추가 자격으로 중복 적용 금지.
- 숫자·날짜는 자료형 분리. 복합 조건은 TEXT로 의미 보존하며 코드 정규화 미완료. 상태 1은 자동 비교 가능성을 보장하지 않음.
- 그룹 설명과 원문 인용 보존. 그룹 간 부모 관계·완전한 AND/OR/예외 논리 트리 미구성.
- 유아학비 적용기간을 나이 기준일로 사용하지 않음. 복지로 2025년 금액 예시는 `reference`로 보존.
- 모든 정책 `draft`, `coverage=partial`, `matching_enabled=false`. 실제 사용자 판정·DB 삽입 없음.

## 재현

backend 폴더의 PowerShell:

```powershell
.\.venv\Scripts\python.exe -m experiments.welfare_classification.schema_sample --experiment data/classification-experiments/20260921T022840428750Z --output data/schema-samples/20260921
```

원문 근거·조건 ID·그룹 참조·상태/값 분리 검증 후 생성. 이번 표본의 검토 매핑이며 범용 정규화기가 아님. 다른 표본의 잘못된 매핑 방지를 위해 입력 파일 SHA-256 일치 확인.
