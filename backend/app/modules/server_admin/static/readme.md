# 서버 관리 콘솔 정적 화면

2026-10-06: 최초 대량 수집/평상시 지속 수집의 일회·자동 프리셋 추가. 자동 프리셋은
revision을 포함한 설정 PATCH로 저장하며 공급자 API 일일 한도는 보존한다. 기존 공고 전체
연결은 끝까지 반복하고 확인/연결 건수를 표시한다. [예산·모델·연구 근거](../../../../docs/ingestion-tuning.md).

FastAPI가 `/`에서 제공하는 한국어 관리자 로그인·서버 관리 화면입니다. CSS와 JavaScript는 `/server-admin-assets/`에서 제공하며 별도 프론트엔드 빌드나 외부 CDN이 필요하지 않습니다.

**서버·프론트 제어**는 개별/전체 종료·재시작, 상태 확인과 영속 작업 결과를 제공합니다.
확인 대화상자를 수락했을 때만 `POST /processes`를 보냅니다. 중복 클릭·저장 전 설정 변경을
막고 작업 결과를 조회합니다. 백엔드 재시작 중에는 최대 120초 동안 연결을 다시 확인하며
종료로 연결이 끊기면 BAT로 기동하도록 안내합니다. 응답 단절만으로 완료를 표시하지 않습니다.
권한 만료 시 로그인 화면으로 돌아가며 이전 세션의 작업 조회가 화면을 갱신하지 않습니다.

**수집 실행**은 원문·소량 분석·직접 설정의 회차 입력, DB 확인·기존 공고 연결,
Windows 자동 수집 등록·해제와 최근 작업 결과를 제공합니다. `POST /operations`는 버튼을
명시적으로 클릭한 경우에만 호출합니다. 실행 중 2초, 대기 중 10초 간격으로 조회하며
메뉴 이동·로그아웃 때 타이머를 중지합니다. 회차 입력은 저장 설정을 바꾸지 않습니다.
진행 중 중복 실행과 저장하지 않은 서버 설정 변경이 있는 상태의 실행을 막습니다.
수집량은 **한 번에 수집할 공고 수 / 수집 반복 횟수**, 모델 한도는 **AI 분석 최대 횟수**로
표시합니다. 입력에 따라 목록 조회량의 상한을 갱신하며, 상세·분석 작업 수와 AI 사용 횟수가
분석 완료 공고 수와 다를 수 있음을 안내합니다. 서버 설정도 같은 용어를 사용합니다.

`index.html`은 로그인·관리 콘솔 구조, `console.css`는 반응형 화면, `console.js`는 동일 출처의 `/v1/server-admin` API를 사용합니다. 기존 최고관리자 계정과 HttpOnly 인증 쿠키를 사용하며 비밀번호·API 키를 로컬 저장소에 기록하지 않습니다. 로그인된 상태에서만 서버 상태, 수집 현황, 변경 이력, 검색 후보, 설정을 읽습니다. 설정 필드와 제한은 서버 응답을 기준으로 렌더링합니다.

설정은 수정한 값만 `PATCH /settings`로 전송하며 `revision`으로 동시 편집을 확인합니다. 기존 비밀 값은 표시하지 않습니다. 빈 비밀 입력은 유지, 명시적인 삭제 체크는 빈 문자열, 새 입력은 교체입니다. 환경변수로 강제된 항목은 읽기 전용이며 DB 설정은 재시작 적용 항목으로 표시합니다. 화면 진입·새로고침·설정 저장은 실제 수집이나 모델 실행을 시작하지 않습니다.

API 호출에는 `credentials: same-origin`과 `X-Auth-Request: 1`을 사용합니다. 인증 만료·권한 실패 시 로그인 화면으로 돌아가며 화면 데이터와 비밀 입력을 지웁니다. 동적 내용은 `textContent`로 렌더링하고 원문 링크는 HTTP(S) URL만 허용합니다.

검증: `node --check console.js`, 격리 SQLite 인증·합성 설정·가짜 공고 저장소를 사용한
임시 ASGI 서버에서 Edge/Playwright로 로그인·설정 저장·충돌 재조회·로그아웃·설정 조회 실패
후 재시도와 PC 1440px/모바일 390px 레이아웃 확인. 실제 공고 DB·공공 API·Codex는 호출하지 않습니다.
