01 · 수동 수집

한 번 실행하기

아래 한도는 이번 실행에만 적용됩니다.

공공 API 목록만 수집합니다. AI 분석과 외부 검색은 실행하지 않습니다.

목록을 한 번 요청할 때 가져올 공고 수입니다.

이번 실행에서 목록을 수집할 최대 횟수입니다. 0이면 목록 수집을 건너뜁니다.

상세 수집과 AI 분석을 각각 1개 작업으로 셉니다. 분석 완료 공고 수와 다를 수 있습니다.

목록·상세·원문 요청과 재시도를 모두 포함합니다.

AI를 사용할 최대 횟수입니다. 추가 분석과 외부 검색도 포함하므로 공고 수와 다를 수 있습니다.

보고된 사용량으로 다음 모델 호출을 제한합니다. 한 호출의 토큰 상한은 아닙니다.

공개 방식은 저장된 서버 설정을 따릅니다.

AI 분석 전용

AI만 끝까지 분석

이미 확보한 원문의 분석 대기열을 처리합니다.

최초 일괄 모드: 최대 16건·입력 10만 글자씩 묶어 남은 공고를 끝까지 분석합니다. 긴 공고는 묶음을 줄이며 원문을 자르지 않습니다. 완료된 공고는 건너뛰고, 중단 후 다시 시작하면 남은 작업부터 이어갑니다. 이번 실행에만 적용되며 평상시 자동 수집 설정은 유지합니다.

기본 모드는 저장된 설정에 따라 최소 4건씩 처리합니다. 두 모드 모두 회차·일일 호출·토큰·총 실행시간 한도 없이 처리하고, 대기열이 비면 종료합니다. 공공 API를 호출하지 않으며 검증 통과 후 공개 설정에 따라 저장합니다.

중지하면 진행 중인 호출의 결과를 보존한 뒤 멈춥니다.
